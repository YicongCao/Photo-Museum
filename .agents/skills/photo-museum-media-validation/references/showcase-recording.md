# 脚本化演示录屏

适用于用户明确要求脚本、单测埋点操作的录屏。普通 UI 检查继续使用当前浏览器工具；不能借录屏提取密码、钥匙串或既有会话。

实际跑通过程：独立 Playwright Chrome → 馆主亲自登录 → 只读核对索引 → 预热本地预览 → 无付费彩排 → 录制 → 标明等待剪辑 → 解码与关键帧检查。用户要求的视口、提示词和故事流必须逐项核对。

- 独立登录窗口等待不要设一小时超时；明确置前。持久 profile、脚本、清单、帧、日志和视频均放忽略的 `data/`。认证只由正常页面登录完成，跨录制 context 仅在内存传递该独立测试会话，不打印或导出凭证。
- 先按完整有序集合找到照片 ID、前后项和页面几何。搜索从真实 facets 选择，核验指定照片确在结果中；API 写请求遵循 Same-Origin 校验。
- 预热只限已有 thumb/display，最多六路；不预取或常驻 NAS 原图。页面显示原图后以实际解码成功为准，不能用固定 sleep 冒充加载完成。
- Cover Flow 开场必须在同一个实际拍摄文档中准备；预热后不要导航到 about:blank 再加载 Gallery，否则会释放已解码图像。持有起点、途经和终点相邻封面的缩略图，等待所有已挂载封面及倒影 img 完成 decode、字体就绪，连续截图和 URL/尺寸指纹稳定后才录制。用不卸载场景的黑色遮罩揭幕。
- 三维画板可能已经 decode 但合成绘制尚未就绪。录前离镜预演实际滑动姿态，再回到起点；短录制文档中可临时保持 transform/filter 合成提示，结束销毁该文档，不把常驻 will-change 写入正式页面破坏空闲性能。逐帧核对运动途中的空白/黑板，不能只检查静止主封面。此流程的实际验证见本机 `data/showcase-1440p/opening-v4/`；准备、重拍均未请求 NAS 原图或重新提交策展。
- 按 DOM 就绪、图片解码及转场克隆清理推进，只有用户指定停留与交互节奏使用固定延时。记录步骤、照片 ID 断言、错误和模型 POST 数量。彩排不提交付费请求；正式提交一次，重录不能偷偷重发。
- CDP screencast 可经 JPEG pipe 写 H.264，但窗口 resize 第一帧可能尺寸异常，编码背压也可能使帧时钟落后于墙钟。先校验首帧和导出宽高；剪辑点必须按实际视频帧复核，不能直接套墙钟标记。若几何异常，比较同一时刻完整截图来区分缩放与裁切；不能把补黑边或放大包装成原生采集。输出帧率不等于页面实际帧率。
- 超出时长预算时，保留浏览交互原速，只压缩或省略模型/索引静止等待，在片中明确标记。FFmpeg 无 drawtext 时可用本地字体生成透明文字图层再 overlay，不为此安装新依赖。
- 用 ffprobe 验证尺寸、比例、时长、编码，用 ffmpeg 全片解码；抽取启动、浏览、选图、返回、输入和真实结果关键帧，核对无错误图标、裁切、长停顿和缺少步骤。素材若拼接多次实际拍摄，记录各源区间，不伪装为连续原速。

2026-10-27 实测产物和私密执行收据位于本机 `data/showcase-1440p/`。公开仓库仅保存方法，不保存真实照片、文件清单、筛选结果或人物信息。
