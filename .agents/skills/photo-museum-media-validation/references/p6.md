# P6 策展助理复验

新对话入口复验见 `docs/research/curator-fresh-entry.md`：先用本地 FakeLLM 创建合成历史，再从 Gallery 菜单进入 `#curator`，确认空输入、无旧结果/事件；手动选择历史能回放，选择“新对话”清空草稿/续写/展厅并清除 URL 的 run。显式历史链接刷新仍回放且不新增任务。不能用真实付费请求制造测试历史。

穿插式运行记录见docs/research/curator-timeline.md。当前隔离P6 fixture上运行node --test web/tests/curator-timeline.test.mjs与node web/tests/curator-timeline.mjs，检查轮次/正文/思考/工具顺序、回放、静默等待/断线、减少动态效果和活动计时器卸载。原p6.mjs有多个同名思考段与状态，须使用first或限定策展结果/任务状态，不能依赖整页唯一文本。不要为展示动画重发正式付费任务。

先读docs/research/p6-curation-assistant.md与ADR0006。生产默认数据data/server；先隔离构建，避免验证期间让正式浏览器加载未完成的JS：

```bash
npm run build --prefix web -- --outDir ../data/p6-validation/web-dist --emptyOutDir
PYTHONPATH=. uv run --all-extras python tools/p6_validation_server.py
```

该fixture复用84张P5合成图，监听8796，使用本地fake SSE provider；等ready后执行：

```bash
uv run --all-extras pytest -q tests/p1/test_curator.py
node web/tests/p6.mjs
node web/tests/p6-layout.mjs
node web/tests/mosaic-layout.mjs
```

P6工具要求读取本地白名单字段；未查到不能放宽条件，人物匹配不导出姓名/脸框/特征。准备阶段重新验证手工日期、隐藏、版本和双缓存；进度按实际项计数，不伪装下载/解码进度。Show的每种展厅必须使用同一集合范围，不能仅照片墙过滤而日历/器材仍显示全库。

慢预热要覆盖280ms首页timer竞争，取消/重启/重连不能重新发付费请求。Schema8升级的旧库fixture须真正移除后来新增表，不能仅修改user_version；生产迁移不能为适配错误测试而跳过错误。

P5回归可复用8796合成源，避免覆盖历史证据：设置MUSEUM_BROWSER_BASE=http://localhost:8796、MUSEUM_BROWSER_OUTPUT=docs/design/previews/p6/p5-regression、MUSEUM_BROWSER_EVIDENCE=docs/research/p6-p5-evidence.json后运行node web/tests/p5.mjs。

真实Provider配置只在本机隐藏交互或配置页输入，不能把key放argv、日志、前端或Git。经用户授权后，可显式运行`PYTHONPATH=. uv run --all-extras python tools/probe_curator.py --config-data data/server --receipt data/p6-validation/live-agent-probe.json`；它访问真实付费provider，但只发送三张生成图的文字索引。失败不能自动重复试费；原始收据仅data。读取真实库时禁网，只读SQLite，不把其中图像、GPS或人物资料用作外发测试。

交付前在线备份旧schema时，不要先构造会自动迁移的新版Database；使用已有只读连接做SQLite备份。正常停supervisor后迁移/配置，再以原数据目录启动。检查API鉴权、五类进程、媒体未暂停与新增完成事件，停止8796fixture，保留8790及用户要求的策展页面。API key不需要再次向聊天发送。

检索工具回归：运行 `uv run --all-extras pytest -q tests/p1/test_curator_search.py tests/p1/test_curator.py`。真实Provider可能将filters双重JSON编码，必须同时覆盖对象和字符串形态，解码失败不能变为无条件检索。真实库地址可含null；按字段筛选和query都不能因此中断。参数错误应带字段路径且不回显原值；内部错误不得伪装成城市不存在。城市字段为最近城市/镇，不能把活动标题或附近镇名当作地级市行政归属。见docs/research/curator-search-tool-fix.md；私密只读重放收据只放data，真实Provider验收仍只发送合成索引。


旅行统计与预算复验：见docs/research/curator-trip-statistics.md。运行tests/p1/test_trip_statistics.py，覆盖全量日期而非前100项、n−1间隔、单/零次、缺日期/未来日期、3/7/14分组、16单轮/64累计/16轮上限。付费合成回归用tools/probe_trip_curator.py，必须显式--live，结果只留data，不自动重复。真实库用只读SQLite备份后禁网核算，不把真实行程外发作为测试。统计任务不应create_exhibition；保留旧失败记录，部署前确认无运行中的付费任务。
