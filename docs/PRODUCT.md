# photo-museum：人生照片集

确认日期：2026-10-24，包含全画布观展、渐进原图与近邻补全修订。此文件描述产品目标，不表示功能已经实现。当前交付状态见 [STATUS](STATUS.md)，本轮关键取舍见 [ADR 0002](decisions/0002-immersive-viewer-and-inference.md)。

## 产品核心

这里保存的是人生经历，不是一个远程文件夹。以一次旅行、一次相聚、一段日常为“展览”，以照片与短视频为“藏品”；同一批藏品可从时间、地点、人物、器材等入口再次遇见。`photo-library` 是旧设想名称，仓库、产品与运行服务统一叫 `photo-museum`。

普通浏览应快速找到照片，创意浏览应帮助重新经历一段记忆。观展是一套全屏、接近游戏的Three.js/WebGL体验，A–F共用一个持久canvas；不再沿用网页页头/页尾和DOM相册的表现方式。管理与欣赏分开：看照片时不出现任务队列、EXIF JSON、模型名称等实现细节。

## 数据契约

- 一个源可以是 WebDAV collection；开发与应急可用只读挂载目录。Mac、Linux 和 Docker 共享同一业务逻辑，正式部署不要求 Finder 在线。
- `年份-月份-主题` 或 `年份-主题` 定义活动；月缺失保留“年份精度”。EXIF 拍摄日期定义藏品时间；目录年月是可回溯的回退依据，不伪造具体日。跨年、跨月、时区不一致保留原始值与修订值。
- 活动根目录中的 JPEG/HEIC/HEIF/HIF 等通常是成片。明确原片目录及 RAW 文件排除展示；嵌套成片目录仍可入库。依据路径、格式、人工例外规则分类，记录命中原因，不能只把 HEIC 当原片。
- 同文件名 MOV 是 Live Photo 候选，优先核对内容标识；一对多需复核。未配对视频正常入库，抽取时长中点帧；时间轴把同一 Live Photo 作为一件藏品。
- “全年总结”等集合可能引用与活动重复的照片。物理文件、媒体藏品、展览成员分开建模，去重后仍保留展览归属。
- EXIF 包含原始拍摄时间及偏移、相机/镜头、实际与等效焦距、曝光、尺寸/方向、GPS、ICC/NCLX、HDR、视频时长/编码等；缺失是合法状态。
- 缺失GPS/部分EXIF可按同目录、可比较文件名序列的近邻实测照片推断，并写入索引；原始/推断/人工/effective值分层，记录供体版本、依据与精度。不能照搬逐图曝光/尺寸/色彩，不借推断值继续推断，不覆盖已有真实EXIF。冲突或证据不足保留未知/待确认。
- 地址结构包含国家代码/名称、省州、城市、区县、街道、社区/区域和展示地址。字段可空；保存 provider、语言、坐标系、精度、来源版本及用户修正。
- 人脸先定位、生成本地向量、聚类，再由用户命名/合并/拆分。“未知人物”是合法结果。相似度不等于身份确认。
- 自动分数分开记录技术质量、美学模型得分、场景代表性和用户偏好；不宣称能客观预测人类喜欢。喜欢、收藏和手工精选优先于模型。

## 首版体验（用户已确认）

1. 首次设置一个站点密码，浏览器只输入密码。服务端保存 NAS 连接配置，可测试连通性。密码、API key 不进入前端包或 Git。
2. 查看扫描进度：发现目录、已列举候选、EXIF 已提取、缩略图/4K 就绪、失败/待复核；分母未完整发现前不显示虚假的总进度百分比。
3. 可暂停、恢复、重试失败项，能发现新增目录与已存在目录新增文件。网络断开后重新接续，不重新处理所有已完成照片。
4. 进入铺满视口的主题场景，筛选年份、打开一场活动；点缩略图优先显示4K，随后后台取NAS原路径的原始成片，渲染就绪后通过数码暗房冲印动画升级细节。已就绪的高质量缓存可直接使用，不被迟到4K降级。暗色单幅细看支持缩放/平移与切图；失败保留4K，不强制等待动画。候选不满足十张时展示实际数量。
5. 每场活动产生至多十张精选候选；去近重复、按时间/场景分布覆盖，支持固定/替换。没有模型时明确使用时间覆盖基线，不把它称为智能审美。
6. 支持视频缩略图、播放与 Live Photo 配对呈现；移动端点击播放，避免依赖 hover 或自动播放声音。
7. 缓存有明确容量上限与可见占用，缩略图优先常驻，4K按需/LRU可重建，原图/兼容高分辨率图/瓦片按需且计入预算。独立管理CPU解码及GPU纹理内存。NAS暂不可用时仍能浏览缓存，原图请求给出可恢复状态。
8. 观展默认视口全屏，主动点击可请求浏览器真正全屏，平台不支持时维持视口全屏。退出、键盘、触摸和读屏有可用路径；设置/管理保留清晰常规界面。

## 逐步开放的展厅

以下都是统一canvas运行时的场景插件，共享媒体状态机、选中项、筛选、纹理调度与输入；不是六套独立网页。实现映射见 [观展运行时](architecture/viewer-runtime.md)。

- 主题长卷：纵向活动、横向该活动胶卷，作为默认入口。
- 时空隧道：右侧年代导航与活动十张精选，用少量层叠图层表现纵深；低动态效果模式使用平面切换。
- 日历：年热力/代表照片、月网格、周细节。未知具体日期单列，不能塞入每月一日。
- 地图：Swiss 排版配地图，国家→省州→城市→活动钻取；明确无 GPS 的活动，手动地点修订可追溯。
- 器材馆：相机与镜头归一化，原创线条图标，按设备浏览偏爱作品；机身型号不是唯一物理相机序列号。
- 满屏照片墙：近方格铺满，随机/时间顺序/自定义筛选与渐进规则；裁切焦点可调，灯箱显示全幅。
- 留白全幅幻灯、双幅对照、胶片长卷、同一地点的时间切片、“往年今日”等。均由相同筛选与播放引擎驱动，保存可复用展览规则。

## 风格与非目标

已选择暖白纸感、Swiss排版，转为画布场景中的视觉语言，暗色用于单幅细看。日期、展览编号、地点成为低干扰的场景文字/HUD，页面导航与页尾不带入观展。[旧概念](design/concepts.html)仅保留色彩气质参考；新的全画布交互先做P0.5风险原型。

首版不替代 RAW 工作流、不编辑或清理 NAS、不提供公网多租户、不做人脸身份自动命名、不把 AI agent 放入刮削必经路径。HDR 完美跨设备一致、全部创意展厅以及个人偏好模型需要各自验收，不能从基础页面能打开推断已经完成。
