# 观展运行时 · DOM 与局部渲染

2026-10-24 修订；[ADR 0003](../decisions/0003-black-ochre-gallery-home.md)取代整页单 canvas 要求。旧运行时方案[保留归档](archive/viewer-runtime-single-canvas.md)，仅用于理解 P0.5 代码与历史实验，不能继续作为新功能限制。

## 页面和渲染职责

React 管理登录、Gallery、馆务、设置与路由。可见文本、活动时间线、表单、工具栏和图表使用 DOM/SVG，媒体优先使用原生 img/video。全屏沉浸是体验约束，不等于必须由一个 canvas 绘制。

Gallery 首版选择 CSS perspective/transform 展板，作为实现方案需实测：每块展板包含至多十张精选，当前及少量邻近活动驻留；其他活动只有数据。CSS 层叠同样有合成层与解码成本，不能创建整库节点或用 translateZ 强制全库上 GPU。发现性能/深度排序问题时，可为展板舞台引入局部 Three.js；时间线和页面不随之迁入 canvas。

照片墙采用虚拟化 DOM 网格与 object-fit 裁切；日历 DOM/SVG；器材 SVG；地图可以使用自己的受控渲染组件，保留署名和许可。原图超出单次解码预算时仍可使用局部瓦片查看器。每种渲染器都实现 mount/update/dispose 生命周期，资源有明确拥有者。

## 共享数据与媒体调度

共享 store 保存活动 ID、照片 ID、筛选、时间锚点、墙游标/随机 seed、缩放和返回焦点。URL 表达可分享给已登录馆主的活动选择，不能携带 NAS 密码。渲染器是视图适配层，不自己创建独立的鉴权/下载系统。

继续复用 P0.5 已验证的分级加载、请求 generation、取消与租约思想；抽取渲染无关状态机，不能把旧 TexturePool 当成 DOM 图片实际内存的准确账本。服务 manifest、revision、会话、原图路径映射沿用 P1。

优先级依次为当前缩略图/4K、当前原图或可见细节、邻近缩略图；后台/离开活动时停止非必要请求与播放。并发、传输临时文件、解码位图、GPU资源分别预算。原始下载不等于可显示，纹理准备只适用于实际走纹理的路径。

## 缩略图 → 4K → 原图

1. 点击后保持现有缩略图，优先显示已解码的4K；缓存已有更高质量时直接使用，避免迟到4K降级。
2. 后台读取 NAS 原路径的当前成片版本。源 ID 与版本受鉴权接口约束，浏览器不接收 WebDAV 密码。
3. 使用原生媒体路径或明确的兼容输出；检查版本、方向、构图和当前选择。img decode 成功也需下一帧可呈现，不能仅凭下载完成开始显影。
4. 高质量可显示时执行短暂、可取消的暗房揭示/淡入。DOM mask/opacity 是优先方案，局部 shader 是可选实现；等待时不模糊、遮黑或永久调色4K。
5. 当前照片改变即撤销旧结果的提交资格；关闭后释放 object URL、解码结果、媒体元素、观察器与局部渲染资源。离线/过期/源变更保留可用预览并准确提示。

大图平移/缩放保持同一图像坐标锚点。超过预算时请求兼容大图或可见瓦片，不把缩小整图叫全分辨率原图。单次全量decode与多级瓦片各自记账；原图、派生与临时磁盘占用均计入缓存限额。

## Gallery 与活动轨道

Gallery 默认 A 时光隧道，首版必须可用。活动面板/精选图布局与时间线共用稳定活动 ID。同年同月活动仍独立；轨道项显示 `MM-主题`，年度项显示 `年度-主题`。若只有月精度，不制造日级先后；采用确定性次序。

滚轮/前后按钮/键盘推进活动，右侧轨道点击直接定位并同步当前项；轨道滚动和场景推进分离，避免事件双重触发。长列表虚拟化，但聚焦活动不得被卸载；保持 aria-current、可访问名称与返回焦点。手机将轨道改为展开式导航，年度主题与同月多活动仍可达。

## 全屏、色彩和可访问性

所有页面 #000000，主题 #B88B4A，见[设计语言](../design/visual-language.md)。照片不受场景光照或全局滤镜污染。原生 img/video 与局部 WebGL 分别验证 ICC、方向、色域与输出；首版准确 SDR，原生 HDR 在 P3 分路径验收。取消“单 canvas”不意味着 HDR 自动正确。

展厅填满视口，系统全屏只由用户手势发起；拒绝时维持视口布局。按钮、时间线与图表采用原生语义和键盘焦点；减少动态效果取消空间飞行但保留导航。地图/局部 WebGL context 丢失时保留共享 store，不要求重扫图库；原生 DOM 路径无需因无 WebGL 而阻断。

## P0.5 保留资产与新的验收门槛

历史 prototype/ 与其测试保留原样，已验证结果不改写成新版性能证明。可复用取消竞态、4K升级、色条、按需瓦片、焦点返回和故障夹具；“只有一个 canvas”和同 canvas 地图探针退出正式发布门槛。

P2 新验收：

- 首次进入 Gallery 就是可操作隧道，来自已索引真实活动，最多十图、不足十图显示实数。
- 同月三活动逐项跳转、年度无月份、长中文标题、切图返回、手机与减少动态效果。
- DOM/局部渲染分别记录当前/邻近节点数、解码并发与资源估计；两万元数据和连续百次选图不造成无界驻留。不能用 CSS 实现就跳过性能验证。
- 4K首次可见、原图迟到/失败、源变化、解码失败与热缓存；动画结束无残留滤镜，旧响应不覆盖新图。
- 登录/会话失效/原图Range/缓存预算继续回归。错误不抹索引、不写NAS。

阶段顺序及退出条件以 [ROADMAP](../ROADMAP.md) 为准。
