# ADR 0007：统一 Settings 与实际偏好生效边界

2026-10-25。独立#settings页面统一文件源、LLM、GPS地址、照片显示及缓存。Dashboard的Settings与策展页Provider入口均指向该页；Gallery菜单增加设置入口，照片展示右上仍保留Dashboard/Gallery/全屏。纯黑黄褐，一屏、侧栏固定，设置内容内部滚动。

保留已保存凭据；不返回NAS密码或LLM key。文件源允许连接新WebDAV源、测试/选活动扫描、修改名称/账户/密码/CA。地址与根目录属于源身份，不原地改写已有记录，变更需新建源。

偏好默认保留现有行为：离线GeoNames解析、推断GPS可参与、最大100km；照片自动取原图、优先准确SDR。可暂停新增地址解析、设置距离/推断边界；地址参数改变只做本地增量重算，不GET NAS，不升级媒体/模型版本。已有地址不因暂停被删除；推断/距离规则贯穿展示与检索。提供显式重算地址入口与真实进度。

HDR偏好只影响单图原文件选择，不改变始终sRGB/SDR的thumb/display缓存。原生HDR优先仅在设备声明HDR能力时尝试，解码失败回退SDR；不代表真实HDR硬件验证通过。按需原图模式在用户点击前零original请求。缓存预算复用现有暂停/预算接口，不自动清理或重建。

偏好服务端持久化、严格白名单验证并检查revision防止多页覆盖；保存立即更新本页，其他页聚焦时刷新。设置中不提供尚未实现的在线地址provider或无效的媒体开关。实现前布局见docs/design/unified-settings.html。
