# ADR 0008：创意展厅复用本地集合与人工编排

2026-10-25。根据已生成的[Gallery 概念](../design/gallery-concepts-2026-10-25/design-notes.md)，新增人生年轮、记忆星图、记忆长卷、故地重游。经典 Cover Flow 仍是首次进入的默认首页，新展厅从 Gallery 菜单进入，沿用照片墙、暗房和返回位置。

四个展厅只投影已有本地索引与 thumb/display 缓存。年轮按已有日期精度归档；星图连线仅表达当前有效本地标签的成员关系；长卷按活动组织章节；故地重游提供跨年同城候选。同城不能自动推断为同地点或同机位，标签相似度不能解释为正确率或人物关系。缺少日期、标签、位置时保留缺失，不为了画面补造事实。

所有读取复用 `ExhibitionCatalog`，P6 通过同一注册函数接入限定集合，不能因换展厅扩大范围。标签额外核对源 revision、媒体处理版本及模型输入，不能把当前分析挂到缓存中的旧版本照片。主题、风格、主体各有独立预览配额，响应保留总数与显示数；分页集合不继承摘要采样上限。

人工成果存于本地 SQLite：长卷保存章节顺序、展示标题与主图，使用 revision 乐观并发；同地点配对必须由馆主选片并明确确认，保存两张照片的 ID 与源 revision。全库与每个 P6 展览分别保存，不改目录、原始元数据、评分或 NAS。未保存配对仅在浏览器会话保存 ID/revision，恢复时必须经当前集合重新解析，不能信任旧图片 URL。

P6 的 Show 扩展到十种现有展示方式，但 agent 没有确认配对、修改长卷或写入 NAS 的工具。这里补齐的是四个具体展厅，不代表所有原计划屏保模式已实现，也不代表概念图中的地理、人物或语义关系已经自动识别。

接口、容量边界与实际回归记录见[创意展厅数据说明](../research/creative-gallery-data.md)。视觉验收与部署结果另行留档。
