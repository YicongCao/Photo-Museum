# ADR 0003 · 黑底黄褐色与 Gallery 时光隧道首页

日期：2026-10-24。状态：用户明确决定，取代 ADR 0001/0002 中的暖白界面、整页单 canvas 与时光隧道延期安排。其余数据、隐私、渐进原图及推断约定继续有效。

## 用户决定

1. 取消整个页面采用 canvas 的要求。
2. 所有页面底色纯黑，主题色黄褐色；刮削管理与其他页面增加有意义的图标和图表。
3. 已生成的时光隧道设计成为 Gallery 首页，第一版必须交付。
4. 右侧 timeline 展示月份和活动名；同月多活动逐项显示，例如 `10-海边的一天`、`10-山间露营`、`10-老友相聚`。

## 实施选择

React/DOM 负责真实文本、导航、表单、时间线、图表与媒体视图。Gallery 优先以 CSS 透视展板和原生图像实现纵深；各活动为一组至多十张精选，不是把每张照片串成隧道。SVG 用于线条图标与统计图。局部 WebGL、瓦片查看器或独立地图组件按实际性能与媒体需求选择，不再要求共用一个 canvas，也不反过来全面禁止 canvas。

所有模式共享选择、活动锚点、过滤条件、媒体请求/取消和缓存预算。移除单 renderer 约束，不复制六套下载和鉴权逻辑。原生 img/video 可作为正式媒体路径；仍分别验证格式、方向、色彩和 HDR，不以浏览器元素可加载证明显示正确。

取消暖白独立入口：登录后进入 Gallery 时光隧道，馆务室为次级入口。P1 现有服务仍是馆务室；P2 实施 Gallery 路由后才切换登录落点。本次计划/视觉调整不伪称 Gallery 已上线。

## 时间线契约

按年份分组，组内每个活动独立一行，标题 `MM-主题`；同月条目不可合并成单个月份点。资产/活动稳定 ID 是选择键，不用月份或标题做唯一键。点击行定位该活动，场景推进同步当前高亮；返回大图时恢复活动和焦点。

年度主题没有月份，显示 `年度-主题`，作为该年的单独分组，不伪造 01 月。同月缺日的活动采用稳定的源路径/ID排序，不声称知道真实拍摄先后。长标题保留完整可访问名称，可折行或展开；不能因右侧轨道狭窄只显示月份。手机采用可展开的活动轨道，仍列出每个活动。

## 首版与验收

A 时光隧道由 P5 提前到 P2，成为首版阻断验收项。P2 按媒体底座 → Gallery/活动时间线/单图显影 → Live Photo/视频/推断与完整验收推进。B 长卷和高级 F 放映可在 P5 扩展，不得用 B 替代首版隧道。

必须验证：同月至少三个活动可分别导航、年度无月份、长标题、手机轨道、键盘/触摸/减少动态效果、活动不足十张、离开大图恢复原锚点。底色计算值必须为 #000000；图表注明统计范围与分母，目录未发现完成时不显示全库百分比。截图与虚构进度概念不当作真实运行结果。
