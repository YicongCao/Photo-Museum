# ADR 0005：P5 四展厅与共享观展上下文

2026-10-25，用户确认实施顺序：日历 → 地图 → 器材馆 → 时空隧道。

经典Cover Flow继续作为Gallery默认首页，新展厅从Gallery菜单进入。地图默认使用随应用发布的本地世界矢量底图，不请求外部瓦片、不向第三方传送GPS。底图与照片坐标使用WGS84，低分辨率底图不作为街道导航或精确行政边界依据，保留来源署名。

先建立[四展厅布局基准](../design/p5-rooms.html)，再顺序实现。纯黑、黄褐、Swiss排版，只有数据标签、操作和必要状态；React/DOM、SVG和CSS透视，沿用共享照片墙与暗房，不强制整页canvas。

1. 日历：年/月/周粒度，日期格用真实本地缩略图与数量。优先effective拍摄时间，目录年月只作年月精度归档；年度、未知月日不伪造为一月或一日。可进入对应照片集合。
2. 地图：世界概览及国家/省州/城市层级，数量聚合、地点列表、活动和照片入口。只使用当前有效GPS及与输入记录匹配的地址结果；近似城市、接受的推断GPS保留精度，缺失与未解析单列。
3. 器材：相机/镜头、使用年代分布、真实统计和评分精选，用户标记可筛选；不把技术评分称为人的喜爱程度。线稿按厂商公开资料核对设备结构，未知型号使用明确的类型示意，不伪造CAD精确轮廓。
4. 时空隧道：独立的纵深行进展厅，与Cover Flow区分；少量活动拼版驻留，滚轮/触摸/键盘/时间线可导航，点击进入活动全照片墙。

共享选择日期、活动锚点和返回上下文。展厅切换卸载非活动媒体，图集与单图返回保留位置；只在单图暗房读取NAS原图。聚合接口需要馆主鉴权，分页和资源上限不允许全库原图预取。公开证据仅合成图，真实照片、GPS与清单继续只放data。

原P5的B长卷/F高级屏保放映不因四展厅上线自动算完成；已有横向活动墙继续可用，后续扩展另列。每个本轮展厅必须有真实数据、空/错误状态、桌面手机与减少动态效果验证。
