# ADR 0004：可恢复媒体任务、单图完成事件与本地策展

2026-10-24，延续 ADR 0003，落实 P2–P4 软件链路与用户的最新馆务交互。

目录枚举、媒体转换、智能分析由独立进程执行，SQLite 记录任务租约、版本、子项状态、下载字节和完整完成事件。`media_jobs.ready` 表示可展示缓存已发布；`file_completions` 表示本版本的媒体和智能子项已检查完毕。两者不能混称。没有模型/GPS的检查使用 skipped，界面可点亮但不能声称得到了人脸/地址。

工作线程不为动画等待。前端通过持久游标领取完整完成事件，逐张从 0 到 100 点亮 100 根竖条；积压时加速，而非跳过文件。进度以子项计数为基础，下载贡献该子项的实际字节分数。它是工作项完成度，不是预计耗时。所有子项 SVG 图标与状态对应；最新正在处理的目录和文件名可见。

默认目录列表来自所有扫描批次发现的最新目录快照；按源和路径去重，不将 4 个根任务误称为 4 个照片目录。每行只统计本目录直接文件，嵌套目录独立，完整列出已发现的待处理项。失败/暂停/当前目录明确显示。全页保持固定视口，列表内部滚动，底部最近 20 项固定照片条。

媒体和推断数据按源 revision 与算法版本记录。模型升级触发对应分析重算，媒体编码版本升级重建相关缓存。真实 EXIF、不确定近邻建议、人工数据分层；相同供体/版本的人工接受或拒绝保持不变。精确曝光等逐文件事实不从邻图复制。Live 配对只有内容标识匹配才确认；同名 MOV 只作候选，确认后不重复占用照片墙。

本地模型选择和许可见 model-manifest.json。第一版以技术质量/构图启发式和近重复、多样性选片，不将得分称为人类偏好概率。人物姓名只由馆主填写；不自动推测身份、年龄或其他人口属性。逆地理使用公共 GeoNames 离线城市库；街道/区域缺失保持空白。

严格遵循纯黑、黄褐和文字减法。Photo Museum 只在管理页出现；观展和播放只保留必要导航、藏品标签、状态。真实照片/脸/GPS和真实页面截图只留在被忽略的 data；公开验收图使用合成素材。

P3 软件部署与 TLS 可实测；物理 HDR/移动设备与用户审美评价属于无法以本机自动测试替代的门槛，报告明确保留，不据此伪称全平台已验收。
