# ADR 0006：P6 受限策展助理

2026-10-25。用户要求以TokenHub hy4-preview自然语言筛选刮削库，实时显示模型返回思考、tools与模型结束后的展厅准备进度。默认temperature 1.1、thinking enabled、reasoning_effort high，须经接口小样实测；不会伪造未返回的思考。

沿用纯黑/黄褐、一屏双栏：左侧对话、结果与输入，右侧可滚动的模型思考/工具事件；结果提供展厅选择和Show入口。Gallery菜单进入策展助理，现有首页不变。独立HTML布局基准为docs/design/p6-assistant.html。

模型只能调用本地白名单检索工具：列结构、库概况、分类值、条件检索、候选详情、创建展览草案。禁止任意SQL、shell、NAS读写、HTTP抓取和修改全库人工策展。活动名和元数据均为数据，不作为指令执行。模型只能引用本轮检索得到的候选/查询句柄，不能凭空创造照片ID。

服务端保管加密provider密钥，浏览器仅见配置状态。工具只回传必要的日期、主题、器材、城市级地址、候选标签、技术分及匿名ID；不回传图片、完整EXIF、路径、精确GPS、人脸特征/人物库姓名。请求和输出历史只存本地data。库检索和推断仍本地，LLM不代替照片识别。

运行过程持久化、支持取消与重连；限制轮次、调用数、时间、输出和候选数量。失败/服务重启不自动重发付费请求。模型完成后按真实数量验证本地双缓存和源版本，报告可用/失效项，再建立本地展览快照。集合展示复用Cover Flow、照片墙、日历、地图、器材馆、时空隧道与暗房；当前隐藏/失效照片不因旧草案重新展示。无结果不擅自放宽用户条件。

用户选择的展厅优先于模型建议；新一轮默认新采样种子产生可变化的选择，同一展览保留所选ID与版本，避免观看时变动。生成草案不改NAS和原有评分/人工标记。公开证据只用合成图库和假provider，真实接口小样不带私密图库资料，真实收据放data。
