# 界面状态与材质规范

2026-10-26。覆盖登录、Dashboard、Settings、Gallery、照片墙、暗房、策展助理及所有展厅；与 [视觉总则](visual-language.md) 和 [烟色时间线](../research/timeline-smoke-glass.md) 一起使用。本文是当前状态系统规范，优先于历史“错误用一个段落”“全控件直角”的概括。

2026-10-26圆环修订：PhotoLoading使用单条二维细线圆环、局部羽化遮罩和5.6秒轻微明暗循环，馆徽仍为2.4秒折叠；标准/小浮层包住馆徽与文字，compact将文字放在小圆旁，避免挤占行内空间。日夜和减少动态效果统一适配，详情见[实现与验证](../research/loading-circle.md)。

## 共同语言

照片保持原色，纯黑是展厅背景，黄褐用于操作和定位。Logo 是三个折叠的照片画板，作为所有媒体/入口读取的工作标记；不新增品牌字样或 slogan。Timeline、主导航、预览气泡与状态横幅使用同一套“清晰文字浮于烟色玻璃”的逻辑：浅灰边缘、有限反光、局部琥珀强调，禁止靠一条醒目的长金线分隔整页。

烟色玻璃必须有可见的底色。在照片之外，状态面板使用有色不透明度的矿物底层，因此背景纯黑或缺图时也能辨识轮廓；不为报错额外下载图片。照片时间线可以复用当前本地缩略图形成漫反射。毛玻璃不能模糊前景文字。

英文展厅/页面标题使用现有本地 Cormorant Garamond；中文、数字与正文沿用现有字体。状态、按钮、数据标签是系统 UI 正文，不使用装饰标题字体。主状态 13px/1.5，中小屏 12px，必要的次信息 11px。状态容器圆角 10px，Timeline 16px，气泡沿用对应材质；原有封面轻圆角保持独立，不将所有控件改成圆角卡片。

## 色彩与形态

根变量在 `tokens.css`，状态语义变量在 `system-status.css`。夜间：文字 #EEEAE1、次文字 #BBB6AC、操作 #DFB778、错误图标 #EDB39C、烟色底 #171E1D/93%、浅灰边 #BDCFC8/18%。日间仅 Cover Flow：文字 #292D2A、次文字 #555C54、操作 #795529、错误图标 #914A30、玻璃底 #F6F7F0/95%。全局连接横幅跟随当前 Cover Flow 的日夜模式，其他页面继续黑底。

图标一律使用 `icons.jsx`：24×24、1.5px 线宽、圆端点；显示 17px，独立按钮命中范围至少 44px。断线用连接断开，超时用时钟，权限用锁，缺内容用照片，服务异常用服务器，完成用勾。错误同时有形状、明确文本和操作，不单靠红色。避免纯红实底、原生弹框和左上裸露错误字符串。

## 状态分解

- **首次读取**：在所属区域中央显示折叠 Logo＋具体对象，例如“读取展馆”“读取照片”“读取设置”。Gallery 首次读取不显示“查看刮削进度”。鉴权检查结束前不显示密码框。首次失败停止 Logo 动画，显示静态 Logo 与错误面板，提供只读重试。
- **后台更新失败**：保留原画面、数据、选中活动和位置。Gallery 位于导航下方中间的紧凑浮层；Dashboard 在数据区内；Settings 在设置内容区。必要时标明“保留当前画面”或真实上次更新时间。绝不把读取失败显示成空图库或全部完成。
- **服务连接横幅**：App 状态读取断线时显示一个全局提示，标明自动重连；同类局部连接错误让位，避免层层堆叠相同错误。导航、已加载照片继续可用。成功读取时自动撤销横幅。
- **表单/操作失败**：提示留在操作附近。保留输入，不自动重发 POST/PUT/DELETE；禁止把“重试”绑定到付费策展提交。重新读取、保存和放弃草稿是不同动作；长卷保存失败保留编辑草稿。
- **空状态**：静态细线 Logo＋简短数据状态；可提供下一步真实入口。空结果与读取失败分开，不偷换筛选条件。背景同步所属展厅主题。
- **局部媒体读取**：照片流右下角折叠 Logo＋“加载照片”；保留现有缩略图直到 4K 解码、绘制及淡入完成。暗房原图失败保留 4K，现有状态条说明降级及原图重试；禁止为了提示动画重复 GET 原图。
- **策展运行**：保留按持久事件顺序的思考/正文/工具日志。环绕线条表示实际运行；重连停止运行旋转并说明正在恢复事件，不重发模型请求。工具日志是用户主动展开的诊断记录，与面向用户的顶层失败面板分开。
- **成功/暂停/待处理**：保留真实数据标签和完成勾；保存成功使用 `SavedStatus`。跳过、未知、失败和完成不得互相冒充。

## 文案与安全边界

请求层 `api.js` 区分连接、超时、HTTP 状态、非 JSON 响应、主动取消。浏览器异常、HTML、堆栈、私密路径或任意服务端字符串不能直接出现在 UI、title 或 aria-label。`status-text.js` 使用受控词表保留已知业务错误含义；未知内容回退为“操作未完成”。新增后端业务错误时补充经过审阅的公开文案，不扩大为“任意中文都安全”的规则。

文案使用“发生了什么＋必要时怎样恢复”，不添加口号和重复解释。区分“暂时无法连接服务”和“暂时无法连接 NAS”；不能由前端 fetch 失败推断 NAS 下线或刮削结束。错误密码与会话失效分开。取消/切页造成的 AbortError 不展示。

请求的默认超时为 30 秒，允许调用方显式调整；普通只读轮询本来就有的重连继续保留，不增加隐式写操作重试。API 错误带稳定类别和 HTTP 状态；不把原始响应正文当诊断信息存储在前端。系统组件异常由边界页接住，重新读取只刷新页面，不重放操作。

## 工程组件和职责

- `api.js`：连接/响应解析/超时/取消/HTTP 分类；保留正常 JSON 与 204 语义。
- `status-text.js`：公开错误词表、领域错误映射与安全回退；纯函数，可单独验证。
- `system-status.jsx`：`StatusNotice`（紧凑提示）、`StatusPanel`（首次/空/失败）、`SavedStatus`、`MediaStatus`（紧凑媒体状态）、`ServiceHealthContext`（全局同类错误去重）、`MuseumBoundary`。
- `loading-mark.jsx`：媒体 Logo 与折叠循环；不重新复制 SVG 或造另一个 spinner。
- `system-status.css`：日夜语义色、44px 操作、层级、断点与减少动态效果；在页面 CSS 后导入，避免各页覆盖成不同样式。
- 页面：决定真实状态、区域、恢复动作和数据保留；不能把任意异常当 JSX 文案。Gallery 目录刷新与浏览操作错误分开，避免一次后台成功清除无关操作失败。

## 运动、层级与验证

提示入场 240ms 透明度＋4px 位移；重试期间仅按钮的小线条旋转，不重新播放全屏加载。折叠 Logo 沿用 2.4 秒循环。开启减少动态效果时关闭这些运动，文字/操作保持可用。读屏使用 role=status 或 role=alert，不靠抢焦点来通知。

浮层不得遮挡导航；手机移至两行导航下方。失败状态同样必须保持一屏，内部列表/设置可滚动，整页不滚动。状态层不得给装饰性的遮罩增加拦截点击的全屏区域。

合成验证记录见 [状态系统复验](../research/system-status-validation.md)。UI 截图只能证明布局与状态，不能证明 NAS 网络根因已修复或照片色彩已获验收。
