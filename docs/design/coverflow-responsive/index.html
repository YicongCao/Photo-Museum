Cover Flow：主封面、两翼与时间线

代码几何对照与建议草案 · 合成画面 · 不修改正式 Gallery

预览按容器缩放，尺寸数字均为逻辑 CSS 像素。建议方案是视觉研究，不是生产实现；不模拟真实手势、NAS加载和精确透视命中。

建议规则

  • 主封面始终以屏幕中轴居中，宽度同时受屏宽和可用高度限制；大屏到约900px封顶，空出的空间用于纵深与倒影。
  • 手机5、平板7、笔记本9、桌面11、超宽15–19块驻留（含少量后备，清晰层数更少）；真正醒目的是中央及最近两层，后层渐暗。挂载数量和“看得清的封面”分别考虑。
  • 约1250px以下将时间线收成一个年月入口，点开后保留年／月／活动三层；不用常驻横条和封面争抢面积。
  • 屏高不足600px，优先保证主封面、标题和操作，限制两翼密度。倒影仍延伸到底边，但更早淡出。
