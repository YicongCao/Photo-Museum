# Photo Museum · 首版体验规范

2026-10-24 修订，按用户确认的时光隧道概念与[ADR 0003](../decisions/0003-black-ochre-gallery-home.md)。取消整页 canvas 与暖白入口；全局纯黑、黄褐色、Swiss 信息排版。详见[统一设计语言](visual-language.md)。本文是目标与验收约束，不表示 Gallery 已上线。

## 进入与馆务

首次初始化/以后登录只输入馆主密码。首版完成后，登录直接进入 **Gallery 时光隧道首页**；馆务、照片源和设置是次级入口。图库尚空时在同一黑底 Gallery 给出连接照片源的清晰入口，不显示虚构活动。

当前 P1 已有馆务服务，先同步统一主题与真实目录统计。首版 Gallery 路由和登录落点在 P2 接入；已获接受的隧道视觉是实现依据，旧暖白入口不再保留为主路径。

## Gallery：时光隧道

每场活动是一块展板，最多十张精选，一张主图与若干配图组成照片拼版；活动沿纵深递进。保持参考图的照片比例、安静空间、左下活动展签与右侧时间轴。页面底色纯黑，去除灰雾与大面积反光地面，黄褐色仅标记交互和数据。

当前和少量相邻活动驻留，远处轻量处理；不能一次加载整库原图。前后按钮、键盘、触摸与时间线都可导航。减少动态效果使用平面切换/即时定位，不能要求必须“飞行”才可进入某场活动。活动不足十张展示实际数量，不重复凑数。

### 右侧 timeline

年份为一级组，同月活动按每场一行显示 `10-活动 A`、`10-活动 B`、`10-活动 C`。实际标题使用真实活动名；每项都能直接定位并独立高亮，不用月份做唯一键。长标题支持折行/完整名称，轨道可独立滚动，点击与滚轮不同时触发展板推进。

没有月份的年度活动显示 `年度-主题`，不伪造一月。月精度内没有可靠日期时用稳定顺序，不声称按真实发生日排序。手机将轨道折叠为可展开活动导航；同月多项和年度项不能被裁掉。回到 Gallery 时恢复活动、时间位置和焦点。

## 主题详情与照片墙

点活动展签/“全部 N 张”进入主题详情，精选只是标记，不隐藏其他成片。基础照片墙是近方格满铺、细黑接缝、黄褐选中提示；点图恢复完整构图。DOM 网格、横向胶卷和 CSS 透视均可用于正式界面，不再要求画在同一 canvas。

随机、顺时、倒时、筛选都有可见图标/文字，进度和条件可收起。高级 B 纵向活动/横向胶卷、F 自动放映在 P5 扩展；不能以先做 B 代替首版 Gallery 的 A 隧道。

## 单图与暗房显影

选中缩略图立即保留当前画面，优先显示4K缓存，再从NAS原路径后台取回当前成片。高质量已经就绪时直接使用，不故意等待；迟到4K不能降级。显示前核对当前选择、源版本、方向、色彩与图像坐标，缩放/平移在升级中稳定。

解码与显示就绪后才执行短暂显影揭示，最终画面恢复准确像素，不永久套暖色滤镜。等待时4K保持清楚；未知总量只报阶段，失败时允许重试。减少动态效果用淡入或直接切换。原始文件、小尺寸兼容图、可见原生细节瓦片、原生HDR是不同状态，不混称“原图全部就绪”。

原生 img/video 可正式使用，局部大图/瓦片/WebGL按需要选择。视频点击播放，Live Photo逻辑配对后有一致图标和播放操作；默认不自动发声。当前格式不支持时由服务端提供准确SDR兼容输出。原生HDR仍专项验收。

## 馆务、数据与管理图表

纯黑表面、细线分组、统一线条图标。已有数据先展示源数量、索引数量、worker状态、最近任务/已发现目录分布、暂停/完成/阻断图标与明确动作。扫描仍发现新目录时，处理图必须注明分母只是已发现目录；不显示假全库进度、假耗时或没有采样依据的速度曲线。

P2 缓存和EXIF任务有真实数据后，再接阶段队列、缓存预算环图和失败分类。暂停、恢复、重试可从图表附近直接到达。图表保留文本计数、单位与空状态，不仅靠色块。

原始/推断/人工/effective分层不变；信息层显示来源、精度和近邻依据。目录只知年份不补月份；推断不复制曝光、尺寸、色域等逐图事实。人脸/语义/审美本地分析、可选联网GPS解析、可选OpenAI助理仍按原阶段推进。

## 后续展厅

C 日历以年/月/周组织，未知日期单列；D 地图以国家/省州/城市/活动组织，推断位置显示精度；E 器材以核验线稿和真实器材信息组织。全都继承同一黑底黄褐展签、图标和共享筛选，不强制同一渲染器。地图组件可拥有局部canvas，但来源署名与许可必须保留。

## 首版退出条件

可从密码登录进入真实活动隧道 → 点右侧同月第三个活动 → 打开一张照片 → 先看4K后完成原图显影 → 返回原活动；年度无月份也能完整走通。手机/键盘/减少动态效果都可达。图库空、源离线、会话过期、原图失败不黑屏，不误删索引。视觉和实际行为分别验收，不以生成概念图替代运行证据。
