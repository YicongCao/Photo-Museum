# photo-museum：人生照片集的观看方式

状态：已确认第一版重点与基础视觉方向；细节为实现提案。日期：2026-10-24。

用户已确认：第一版先完成可靠刮削、缓存、主题展览；暖白纸感 + Swiss 排版，沉浸看图转暗；识别本地运行，GPS 解析必要时可联网，只有确实需要 agent 时才接入 OpenAI。这些选择不需要重复询问。

## 产品主张

photo-museum 应让人愿意再看一次自己的生活。首页的单位是一次经历，照片是展品，人物、地点和设备是重新理解经历的线索。目录结构保持原貌，展览层可以重新组织它：同一照片允许进入多个展厅，不移动 NAS 上的文件。

“museum” 不必等于庄严、复古、模拟实体展柜。它更适合表达时间、珍视与主动策展。界面主语言使用「展览」「照片」「地点」「人物」「器材」，后台使用「来源」「刮削」「缓存」「任务」，避免每张照片旁都出现数据库或模型术语。

先把一条体验做好：进入 → 看见一次活动的代表作 → 完整看图 → 继续看当时的其他照片 → 留下自己的选择。可靠性、流畅加载、正确颜色，比同时开放六个复杂入口更重要。

## 三种视觉方向

共同基础：照片最大化、固定节奏的网格、清晰日期、克制色彩；中文字用系统无衬线字体，数字使用等宽数字。正式版本不依赖外部字体服务。

| 方向 | 观看气质与布局 | 适合场景 | 需要验证的取舍 |
| --- | --- | --- | --- |
| A 暖白纸感 + Swiss 排版 | 温暖背景、细分隔线、大留白的展览标题、左对齐网格；点击照片进入深色灯箱 | 日常翻阅、家人共看、地点与器材的文字叙事 | 不能让“纸感”纹理影响照片颜色判断；留白仅用于展览页，满屏墙仍铺满 |
| B 深色摄影美术馆 | 炭灰背景、首图更大、文字更少、左右不对称展陈；元数据收在抽屉 | 大屏沉浸、夜间看图、TimeMachine | 暗色不代表 HDR；暗部层级与弱视可读性需要实机验收 |
| C 极简档案馆 | 浅灰工作台、紧凑标题、统一大小缩略图、日期与器材标签更显著 | 大库检阅、筛选、比较、后台任务 | 不能把首页变成网盘；“本周重看”与代表作仍保留人生叙事 |

已采用 A 为基础，灯箱和屏保使用 B，管理页吸收 C 的高信息密度。概念页保留其他两种方向作为比较工具，正式首页按已确认的暖白方向推进。

离线交互稿：[concepts.html](concepts.html)。它使用虚构的主题、日期及内嵌 SVG 示意图，能切换三种视觉方向、三种虚构活动、展览/隧道/照片墙，并打开灯箱。它没有连接照片库，不能用来验证真实图像解码、颜色、HDR 或加载性能。

## 信息架构与核心页面

- **展览**：时间顺序的活动主题。每个主题一张封面、最多十张代表作、地点和时间范围；完整照片展开后再按需加载。
- **日历**：按拍摄时间定位。活动名称仍可跳转；单张照片允许属于拍摄日和跨月份主题两种组织方式。
- **足迹**：地图与国家/省份/城市的文字索引；不想看地图时仍能完成同样操作。
- **人物**：用户命名的人物及待确认分组；未命名的人脸不自动猜名字。
- **器材**：相机和镜头的个人使用史；有意义的照片优先于参数排名。
- **收藏**：主动收藏、精选展览、同景不同年、用户笔记；作为个人价值的稳定入口。
- **放映**：全屏屏保。共享过滤条件、顺序、节奏和裁切设置，不再复制一套收藏系统。
- **管理**：来源连接、当前任务、队列、失败重试、排除/待确认、空间和 provider 状态。入口与观展路径分开。

所有展厅共享可保存的筛选：年份/月份/活动/地点/人物/相机/镜头/照片或视频/收藏/未看过。筛选应在 URL 中可复现，但 URL 不含 NAS 凭据或原始绝对路径；登录后恢复当前展厅和筛选。

## 六种原始设想如何实现

### A 时空隧道

一次活动是一块“展板”，呈现最多十张代表作，当前展板清晰，前后展板缩小、后移、降低对比度。右侧时间线先按年定位，再展开月份与活动；一年范围活动标为“全年/日期待确认”，不放到虚构的一月一日。

使用 CSS 3D transform 表现层级，活动数据采用固定窗口虚拟化，仅维持当前和相邻两三块展板。3D 只改变视觉，DOM 阅读顺序仍按时间排列。滚轮每次推进一块活动，同时提供上一场/下一场按钮和方向键。进入主题后不再劫持横向滚动。图片不足十张时展示实际数量。

移动端改为单层展板和底部时间选择器，不把桌面的十张照片强塞入一屏。`prefers-reduced-motion` 下取消透视与飞行动画，改为淡入或即时切换。真正连续后退的视觉需要以真实缓存库测量内存、帧率和预载预算。

### B 纵向活动、横向照片

这是推荐的第一版主体验。纵向浏览活动，活动行内横向浏览代表作，点击“全部 N 张”进入主题详情。不要让横滑成为唯一入口：有明确箭头、进度和“全部”按钮；移动端采用原生触摸滚动与 scroll-snap。

每行保留一个稳定标题栏，避免滚动时只剩图片却不知道是哪次经历。纵向活动虚拟化，横向照片先加载 3–5 张和下一组；封面可以单独指定。主题详情默认时间顺序，精选标签是叠加标记，而非永久隐藏其他照片。

### C 大日历

年视图显示十二个月的小图阵与照片密度；月视图每格一张人工/算法选封面、照片数量和视频标志；周视图允许每日更丰富的胶卷。点击一天进入日相册，切换尺度维持同一时间锚点。

日历来源以照片拍摄时间为主，保留时区与不确定性；文件修改时间只可作为明确标记的降级信息。年/月主题不推断出具体拍摄日；无可靠日期的内容放入“日期待整理”。同一日跨两个活动时不强制合并。键盘方向键导航日期，日历有列表替代视图。

### D 地图 + Swiss 地点索引

桌面左侧大地图、右侧固定宽度的地点文字与主题列表；国家 → 省级行政区 → 城市 → 区/街道逐级收敛。缩放地图只更新当前地图结果，不悄悄覆盖用户已选条件。首次以活动聚类，深入后才显示照片点，避免十万级点同时渲染。

保留原始 GPS 与解析地址的来源、语言和精度。地图展示可对外隐藏精确坐标；没有 GPS 的活动可手工关联地点，并标明“人工标记”。地点层级因国家不同而不同，缺失项显示为空或当地行政术语，不生成假的省份或街道。

地图瓦片也是外部数据访问：离线或本地模式下提供离线底图/仅地点列表；云地图 provider 与逆地理 provider 可分别启用。中国境内坐标体系需由适配器显式转换并保留 WGS84 原值，不能在前端反复猜偏移。

### E 器材馆

每台相机配原创单色轮廓图：先建立相机类别的统一线条语法，再根据实际设备型号做人工审核的专属图标。图标是视觉标记，不以模型生成的猜测外形冒充准确产品图。厂商品牌标识不作为本站主品牌。

设备页显示首次/最近使用、常用镜头、典型焦段和用户收藏的照片；可挑选“这台相机陪我去过哪里”。机身与镜头是两种筛选维度，同型号但不同设备若无法从序列信息可靠区分，就先视为同一个型号，不伪造物理设备身份。

有趣的展览包括「第一台相机到今天」「同一焦段的十年」「换相机后我仍然在拍什么」。统计是帮助回忆的附录，不把价格、像素或机器评分当作照片价值排序。

### F 满屏照片墙与放映

满屏近方形网格根据容器宽高计算列数和行数，每格 `object-fit: cover`，填满视口；小范围变形不用于填满。每次切换只替换一部分格子，避免整屏同时闪动。照片位置尽量稳定，当前视口提前加载下一批。点击打开完整构图；可把人物/主体焦点作为裁切参考，允许人工调整。

同一过滤器支持随机、从老到新、从新到老和用户自定义渐进。随机使用可恢复的 seed + 游标，避免一刷新就重复；“渐进”明确表示先按年、城市、人物或设备分组，再在组内按日期排序。

除网格外再提供：

1. **双页相册**：一张主图配 1–3 张辅图，轮换主题章节，适合完整构图。
2. **胶片长卷**：同主题照片缓慢横移，暂停可交互；不使用连续快速飞行。
3. **单幅静观**：每幅停留更久，保留原始比例，背景取暗色/中性色；适合 HDR 实机观看。
4. **同景回声**：同一地点不同年份的两张照片并排，不自动宣称为相同视角，匹配需允许确认。
5. **一日一章**：按当年今日/同月挑主题，附可关闭的日期和活动名。

所有放映均有清晰退出、暂停、速度和静音控制。默认无声；Live Photo 只在显式播放或用户开启“动态放映”时动起来。不要把后台视频自动播放当作默认展示。减少动态效果偏好下关闭自动位移，保留手动翻页。

## 每个活动的十张代表作

“最具代表性”和“最可能受欢迎”应分开。前者需要覆盖叙事、人物、场景和时间；后者只能是参考模型和个人反馈的偏好估计。

建议候选流程：技术可用性（解码、极端模糊、误触）→ 相似/连拍分组 → 语义、人物和拍摄时段覆盖 → 构图/美学参考分 → 多样性选择。合影、宠物或纪念瞬间即使技术分较低，也可能因为用户收藏而优先。照片不足十张时不补重复项；没有可靠内容分析时降级为时间分段选样并清楚标记。

用户可固定、替换、排序十张代表作；固定结果跨重刮削保留，新版本只提出待采纳的变化。展示「你选的」「系统推荐」，不向观众默认展示“你的生活 72 分”。照片收藏、活动代表作与主题封面是三个独立操作。

## 灯箱与媒体行为

灯箱是所有展厅统一的看图方式。显示完整构图，支持缩放、拖动、上一张/下一张、收藏、信息抽屉、原片格式说明。初始立即显示本地 SDR 缓存；在浏览器和显示设备确实支持时才切更高质量的原生成片。界面不得把普通屏幕上的色域能力标志当作真实 HDR 解码已成功。

Live Photo 是一张照片及其动态伴随资源，网格只计一次，有可见 LIVE 标志和点击/按住播放入口；键盘同样可播放。普通视频单独计数，显示时长和中帧海报，不假装是一张静态照片；点击才加载视频流。转码进行中展示明确状态，已有海报仍可浏览。

元数据抽屉优先时间、活动、地点、机身/镜头/曝光，再显示原格式、色域和详细来源。地点、人脸和笔记都可隐藏；跨设备访问只通过服务端授权 URL，不把 WebDAV 凭据交给浏览器。

## 管理界面

“刮削”拆成可理解的阶段：发现目录 → 识别成片 → 提取信息 → 生成预览 → 可选增强 → 选择代表作。每阶段显示已完成/待处理/失败/跳过及正在处理的主题。未知总量时显示“已发现 N 个”，不显示伪精确百分比。

用户操作包括暂停/继续、重试失败、重新处理指定主题、查看排除原因、调整队列优先级。改变规则之前显示影响预览；重跑时保留用户收藏、人物命名和代表作固定。后台任务失败不影响已经入库照片浏览。

缓存空间用“已用／上限／待生成估算”表达，说明 4K 是长边 3840 像素的预览而非全分辨率原文件。可释放缓存并重建，但“释放缓存”绝不删除 NAS 原文件。原片排除是索引规则，不是清理按钮。

登录只需密码，无用户名字段。首次设置、会话过期和登出是完整闭环；NAS 密码与网站访问密码是不同用途，界面清楚区分。错误提示不透露照片路径或认证凭据。

## 建议推进与验收

1. **概念确认**：基础风格、第一条体验与隐私边界已确认；用同一批内容确认暖白方案的具体展览布局，避免照片质量影响设计选择。
2. **真实数据窄切片**：选 2–3 个真实主题，覆盖 JPEG、HEIC、Live Photo、普通视频和有/无 GPS；只运行只读刮削和本地缓存。
3. **主路径验收**：密码登录、断点继续、主题浏览、完整看图、视频/Live Photo、收藏、手动十张代表作。使用真实桌面和手机验收，不把合成占位图表现当作实际速度。
4. **展厅扩展**：先照片墙和日历，再地点和器材；TimeMachine 在主路径稳定后加入，以性能和低动态替代路径作为发布条件。
5. **智能策展**：启用可替换的本地识别 provider、比较自动代表作与用户选择，允许撤销和重跑；GPS必要时另接在线provider。

验收重点：从浏览到完整图不丢日期锚点；触摸不误触横/纵滚动；键盘可到达所有操作，灯箱关闭回到原焦点；不按颜色区分唯一状态；长主题名、跨年月、零照片、加载失败均有布局；屏保不裁掉用户明确固定的主体；20 万条索引的前端不一次加载全量；动态效果能关闭。
