# P6 策展助理：实现、配置与验收

2026-10-25。本轮交付自然语言检索、受限agent tools、实时过程、展览草案及六种Show方式。入口：<http://127.0.0.1:8790/#curator>，也可从Gallery菜单进入；不替换Cover Flow首页。方案见[ADR 0006](../decisions/0006-curation-assistant.md)，实现前保存了[布局概念](../design/p6-assistant.html)。

## Provider与模型提示词

用户指定TokenHub `https://tokenhub.tencentmaas.com/v1`、`hy4-preview`。使用Chat Completions流式协议，temperature **1.1**、`thinking: {type: enabled}`、`reasoning_effort: high`。依据[腾讯深度思考说明](https://cloud.tencent.com/document/product/1823/131208)与[混元调用指南](https://cloud.tencent.com/document/product/1823/132252)，在工具结果回填时保留该轮模型返回的reasoning_content；不虚构未返回的思考，不把它当成已执行操作。其他自定义网关/模型未被本次实测自动覆盖。

密钥只由服务器使用，复用Fernet加密后存本机settings。浏览器只拿到configured状态和非密钥配置，编辑器API key始终为空，留空可保留；更换地址须重输key，禁止带密码/查询串的URL。CLI可用`PYTHONPATH=. uv run --all-extras python tools/configure_curator.py`，交互隐藏输入，不把key写进命令行参数、前端、Git或日志。备份包含服务端加密密钥，继续按私密数据管理。

[系统提示词](../../photo_museum/curator-prompt.txt)包含项目背景、馆主中文/少说明/黑底黄褐/Swiss/沉浸偏好、数据精度、技术评分和候选标签边界、六种展厅，以及工具限制。用户指定展厅优先，auto才允许模型建议；每轮使用新种子，已生成集合则固定ID和源版本。

## 可用工具与数据

- `catalog_schema`：真实字段、可筛条件、未知精度和展示方式。
- `library_overview`：可展照片、年代、缺失信息和本地模型候选覆盖。
- `list_facets`：真实的活动、年份、相机、镜头、国家/省/最近城市、style/topic/主体类别及数量。
- `search_photos`：结构化AND/OR过滤、日期范围、标记、有人/本地人物标签、方向、分数，以及ISO/光圈/曝光秒数/实际焦距范围和HDR；按时间、评分、随机或跨活动多样性排序。
- `photo_details`：本轮已检索候选的精简摘要，包括尺寸、曝光、色域/位深/HDR、候选标签和来源精度；不加载图片。
- `create_exhibition`：用本轮查询句柄或已出现的候选ID生成草案，不能凭空指定照片或改全库标记。

未知数据不充当命中：年度不伪造月日，未接受推断不参与；逐文件曝光不能从邻图复制；旧版本模型结果不可当当前候选。空结果保持原条件，不能偷偷扩展年份/地点或展示无关图库。图片、文件名、NAS路径、完整EXIF、精确GPS、人脸框/特征和人物库姓名不会作为tool结果发送；人物标签仅本地匹配。发送的是用户策展要求及必要的日期/主题/器材/城市级地址/技术分/候选标签等文字摘要。

每轮最多8次模型往返、24次工具调用、240秒；单次输出/上下文、工具参数、结果与选片数有上限，草案最多1000张。无任意SQL、shell、HTTP抓取、NAS读写或元数据修改工具。模型不得把活动名/标签中的文字当指令。失败、限流、取消和重启均不会自动重发付费请求。后续“延续本轮”只带上一轮要求和简短结果，重新检索，不复用旧候选权限。

## 实时过程和Show

持久化runs/events/exhibitions（schema 8），SSE带游标，断线重连或重载会重放去重事件，不重新启动模型。页面分别显示provider实际返回思考、工具名称/参数/结果摘要/耗时、最终答案、取消/失败状态和token用量。长内容在内部滚动；用户停在底部时跟随新内容，手工向上阅读时不强拉回。

模型结束后，服务重新核对当前版本、隐藏状态、筛选条件和本地thumb/display文件，按实际检查数量报告`checked / total`、可用和跳过数；这不是NAS下载或GPU解码百分比。不满足条件的条目不发布。然后提供预览和Show选择。

同一草案可按Cover Flow、照片墙、日历、地图、器材馆、时空隧道展示。所有聚合/活动/分页接口都受该集合ID和源版本限制，不会把全库混进日历/器材统计。仍需馆主登录；旧草案中的隐藏、缺失、越界或换版照片不重新显露。展示复用4K优先、按需NAS原图、暗房和资源取消流程。

慢速验证修复了“首页预热timer抢走策展墙预热”的竞争；同时补齐1–9张照片的封面拼贴，保持真实数量且不留空洞。手机与矮窗口一屏，仅对话和过程区域滚动。
