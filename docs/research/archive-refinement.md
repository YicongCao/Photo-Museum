# 照片档案精简与摄影风格诊断

2026-10-26。正式照片档案按本轮要求精简字段，并统一EXIF和刮削生成的数据行。没有修改原始EXIF、识别结果、模型门槛或pipeline版本。

- SDR源图不再重复显示“sRGB · SDR预览”；HDR源图继续说明sRGB/SDR预览转换。色域、位深和源HDR/SDR信息仍保留。
- 焦距只显示EXIF中已有的35mm等效焦距。实际焦距存在但等效值缺失/为0时显示“未记录”，不把实际焦距冒充等效值。
- 原GPS坐标行改为“近似城市”，优先中文城市名。没有解析城市时显示“未解析”；旧城市若对应不同GPS记录，不再展示。未接受的位置推断建议也不显示原始坐标。地图所需坐标仍保留在本地数据中，没有删改元数据。
- EXIF与刮削生成的评分、主体、风格、主题共用`ArchiveRow`和同一组dl/dt/dd样式，统一图标、黄褐标签、正文、间距和分隔线。
- 标题删除“候选”二字，Dashboard对应标签也统一为摄影风格/摄影主题。悬停信息保留本地模型推断、未校准、相似度及领先基线，底层候选语义和agent边界不变。

## 摄影风格不是全部未识别

对当前有效策展口径18,246张照片，18,246条摄影分析均有效且有风格处理状态：2,627张有风格结果（14.4%），15,619张未确定（85.6%），没有这批记录的风格执行错误。当前14种风格均有输出，例如浅景深虚化863、动态抓拍497、逆光剪影295；一张照片可有多个风格，标签次数不能相加冒充照片总数。

`select_candidates`要求余弦相似度至少0.225，并领先普通照片/非照片中较高的基线至少0.01，且最多3类、同组互斥。取数已过滤当前源revision、媒体版本、预览更新时间和摄影模型版本，未把旧结果混入。

又固定种子抽取8张未确定、8张有结果的本地缩略图，使用当前校验通过的本地模型/词表复算分数。8张未确定中，6张最高风格分低于绝对门槛，2张没有足够领先基线；网络尝试0，没有下载原图或模型，也没有将复算标签写回数据库。此样本解释拒绝判断的机制，**不证明模型准确率**，没有人工风格标注集可用于校准门槛。见[汇总](photography-style-audit-evidence.json)。逐图样本仅保存在data/archive-refinement/。

因此本次保留这项能力，**照片档案不再渲染“未确定”的空风格行**，已有结果仍显示并可用于检索。Dashboard处理检查器继续如实显示未确定，便于知道该子任务已处理。风格与主题共享同一次CLIP图像编码和文本相似度计算，单独去掉风格不会省掉主要模型计算；不为了增加覆盖而直接降门槛。模型是否值得长期保留，应以后续人工样本验收判断，不凭非空数量冒充质量结论。

可重复诊断入口：

```bash
PYTHONPATH=. uv run --all-extras python tools/audit_photography_style.py \
  --database data/server/catalog.sqlite --models data/models \
  --output data/archive-refinement
```

该工具只读SQLite、禁网，并限制图像输入在本地cache内。若本地模型版本与当前库不同会停止复测；具体照片关联与分数收据只留忽略目录。
