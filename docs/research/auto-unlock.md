# 已填充密码自动解锁

2026-10-25。仅前端改变登录触发方式，馆主鉴权、会话与服务端限速不变。

登录页发现自动填充或粘贴的密码稳定约750ms后，通过原表单尝试解锁，保留Gallery/Dashboard目标路由。以input/change事件和仅在登录页存活的轻量值检测覆盖密码管理器不派发事件的情况；密码从当前表单取值，不读取钥匙串或浏览器凭证库。

手动逐字输入期间不因停顿发送半截密码，Enter和按钮照常可用。一次填充值只自动尝试一次，错误后保留错误与手动入口；填充值更正可重新自动尝试。同步请求锁阻止自动、Enter、按钮并发产生重复请求。首次设置密码不自动创建账户；明确点击锁定后，本页保持锁定，不因密码管理器再次填充立即重新打开，仍可手动解锁。

检测器卸载时清除计时器、监听和临时字符串引用；不持久保存密码、不记录日志。它只能处理浏览器向页面提供的填充值，不绕过浏览器或密码管理器的用户确认限制。

验证：`npm run build --prefix web`；独立启动`PYTHONPATH=. uv run python tools/p1_validation_server.py`（8791），ready后运行`node web/tests/auto-unlock.mjs`。全程使用隔离的合成密码，不读取真实凭据，也不覆盖正式浏览器Cookie。

10项浏览器检查通过，覆盖初始化之前已填充、初始化之后静默填充、replacement/paste事件、逐字输入暂停、错误去重与更正、并发提交、显式锁定、首次设置、Gallery路由及无未捕获错误。浏览器证据见auto-unlock-browser-evidence.json，公开截图只来自合成服务。模拟静默DOM填充和输入事件不等于已逐个验证Apple Passwords、Safari或所有第三方密码管理器。
