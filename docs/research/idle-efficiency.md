# 空闲 CPU、轮询与绘制复审（2026-10-27）

## 结论与测量边界

正式 8790 已更新。真实图库、同一照片流位置下，API＋六个 worker＋supervisor 的一分钟平均 CPU 从 **12.53% → 8.21%**，约下降 **34.5%**。100% 是一个逻辑核心，本机 10 核；不是整机占用 12.53%。两次采样的完成事件游标、媒体状态分布和近期分析计数均未变化，没有通过暂停正在刮削的任务制造收益。

真实采样用 `ps` 累计 CPU 时间差 / 实际墙钟间隔，每约 2 秒采样、30 组；原始数据仅 `data/idle-efficiency/{before,after,final}/`。中间版本是 11.28%，发现额外客户端持续请求 Dashboard/Settings 后，补入服务端状态快照，最终为 8.21%。生产页面始终恢复原照片流的 31% 位置，会话保留。对照并非严格隔离的硬件实验，单次结果存在系统负载与缓存波动。

API：7.93% → 5.29%；worker 合计：4.58% → 2.92%；supervisor：0.02% → 约 0%。日志只临时记录路由模板、状态码、耗时，已关闭诊断开关。没有关闭或操作其他用户页面。

## 浏览器对照

使用隔离 P5 合成图库、独立 Chrome context、1600×900，同一个 API/图库分别加载保留的旧构建和新构建。没有 rAF 采样器，避免测量工具自己持续提交帧；CDP trace 统计 Paint/DrawFrame，Performance.TaskDuration 统计主线程时间。Dashboard 固定为无活动、无完成事件的暂停状态，验证空闲工作量，而非刮削吞吐。

- Cover Flow 静止 45 秒：接口请求 **21 → 6**；强制合成 `will-change` 提示 **1 → 0**。主线程 27 → 29 ms，不能据此声称主线程加速。
- 照片流静止 10 秒：接口请求 **4 → 0**（处于退避阶段，并非永久停止鉴权检查）；主线程 5 → 4 ms。
- Dashboard 静止 10 秒：计时器回调 **1,049 → 3**；接口请求 **12 → 5**；主线程任务 **91 → 7 ms**。
- 隐藏 Dashboard 6 秒：**0 轮询、0 计时器回调、0 运行中动画、0 Paint / DrawFrame**。返回可见状态后 750 ms 内已开始读取。
- 上述三个可见静止页面，优化前后都为 **0 Paint、0 DrawFrame、0 持续动画**。没有证明可见静止 Gallery 的 GPU 帧率进一步下降。

浏览器不能命令硬件 GPU 进入休眠。此处的边界是页面不再主动提交持续绘制、隐藏页不持续运行动画。整机 IOAccelerator GPU 均值 46.6% → 35.2%，包含 Codex、其他页面、WindowServer 和测试过程，**不能归因于 Photo Museum**；未获得单 IAB 页面硬件 GPU 占用率。保留反射与毛玻璃材质，未用视觉降级冒充 GPU 优化。

## 实现

### 后台与 SQLite

- `worker_runtime.run_loop`：无任务时版本探测从短间隔指数增长到最多 5 秒；有任务立即重置并连续处理。时间驱动的租约/重试仍每 30 秒全检查，变更在最多约 5 秒内被发现（不含实际数据库竞争、查询或已有任务耗时）。
- 目录 worker、lexicon worker 接入轻量变化探测；词库探测包括配置/目录版本、构建代与 dirty 队列，重建不能因为无照片变化而漏唤醒。
- 目录/媒体/词库 5 秒心跳独立保留，不能把休眠误报为进程离线。SQLite BUSY/LOCKED 保留重试日志和恢复，永久错误仍抛出。无 revision 的通用调用有 30 秒上限的指数退避。
- `/api/state` 对来源、任务、封面与数量投影复用版本化快照；鉴权及 `worker_online` 每次实时检查。变更失效，不缓存失败。避免其他尚未刷新的客户端反复执行同一套查询。
- `/api/gallery?since=<revision>` 鉴权后检查真实 catalog 版本；相同只返回 revision/unchanged，不重新投影、序列化和传输封面清单。限定策展集合不走全库 since 捷径。
- supervisor 从 4 Hz 降到 1 Hz 检查子进程；重启退避和退出清理保持。

### 前端

- `adaptive-poll.mjs`：单飞读取、完成后调度；无变化/失败指数退避。馆务/会话最多 30 秒，设置/词库最多 60 秒，Gallery 最多 120 秒。任务活动维持原刷新频率；页面首次加载、恢复可见、窗口 focus、网络 online、成功写操作即时唤醒。显式重试仍即时，写操作不自动重放。
- 隐藏页清除轮询定时器；在途响应仍有原取消/卸载保护。不更改后台 worker 生命周期，不把“没打开 Dashboard”变成停止刮削。
- 相同数据不重复 `setState`；设置页不再跟着全局轮询读取 `/state`。照片流/单图期间不刷新整个封面目录，回到展厅立即核对版本。
- Dashboard 原 8 ms 永久队列检查改为事件驱动。没有新数据/动画时不再自唤醒；排队完成仍逐根点亮 0→100。隐藏时暂停、返回继续；真实活动中的单图档案仍 1 秒刷新。
- 移除时空隧道、星图和玻璃栏的永久 `will-change:transform`，Cover Flow 的提示只在真实移动期间设置；显影完成移除显影 class 及其扫光伪元素。隐藏页统一暂停 CSS 动画，保留可见加载反馈。
- 登录密码填充侦测空闲时退到最多 1 秒，输入事件恢复快检查；隐藏时停，保留手动输入不误提交、错误自动填充只试一次和锁定语义。策展运行的秒表在隐藏时停，回来按真实时间更新，不影响模型任务。

## 剩余开销复审

1. **其他仍打开的旧页面轮询**：正式请求记录中仍有 Dashboard/Settings 的周期读取；当前前台是照片流。已从服务端减少重复投影，这些客户端加载新版本后才采用新的退避；没有擅自关页。其数量/行为不属于当前页面的零帧证明。
2. **必要的后台兜底**：5 秒心跳、最多 5 秒的版本读取、30 秒超时/重试检查仍访问本地 SQLite。零 CPU 会失去新任务发现、租约恢复和可靠在线状态。下一步可研究跨进程通知，保留兜底，不在本轮引入易丢唤醒的信号替代数据库事实。
3. **正在工作的反馈**：原图进度 300 ms 轮询、可见加载标志、活跃策展 SSE 与秒表、处理中进度动画仍保留，完成/卸载时清理。这些是活动状态成本，不是静止封面常驻循环。
4. **重绘时的图像与合成成本**：4K 解码、3D 画板、反射模糊、毛玻璃仍有内存/运动期间 GPU 成本。静止零帧不等于纹理内存释放；动画性能需另按真实图片/分辨率测量，不以 CSS 属性数量代替 GPU 实测。
5. **数据源边界**：空闲版本探测只查服务器本地库，不会为了刷新界面访问 NAS。只有真实待执行扫描/媒体任务以及用户单图查看访问源；原图不加入持久缓存。
