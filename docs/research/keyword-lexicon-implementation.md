# 全局关键词词库：实现与验收

2026-10-26。已按[批准方案](keyword-lexicon-plan.md)实现已有元数据的二次索引；主体、摄影主题、摄影风格和城市各自保留身份。设置入口为 `#settings?tab=lexicon`。构建不取 NAS 原图、不解码照片、不运行识别模型、不调用 LLM；普通刮削和既有人工数据继续保留。

## 数据与增量更新

SQLite schema 11 增加词条、别名、照片关联、构建代际、单例状态和持久 dirty 队列。主体优先公共 ImageNet synset；兼容旧数字/英文 ID 的确定映射。显式其他 taxonomy 不强行按 ImageNet 编号解析。未知主体使用带来源 taxonomy/原标签的临时 ID；不能声称已消歧。topic/style 沿用本地词表 ID。城市优先 GeoNames ID，缺失时用包含国家、省份、城市名的临时标识；同名不同 ID 分开。

每个词条记录标准 ID、显示名、中英文/原始别名、来源版本及不同照片计数。别名检索仅做 NFKC、大小写及空白规范化；原文保留。一个别名允许对应多个词条，按分类和国家/省份消歧。同一照片的重复标签、别名不会重复计数；界面的同字别名合并展示其全部来源。城市仍为最近城市/镇近似，不是行政归属。机器标签保留 candidate 身份，相似度不当正确率。

entries、analysis、metadata、curation、media_info、media_jobs、cache_files 的相关变更通过 SQLite trigger 在原事务内入队；回滚也回滚入队。缓存访问时间更新不入队；UPDATE触发器仅在相关值实际变化时入队，旧媒体队列反复写相同stale状态不会让词库忙转。worker 每批最多128个 asset，使用同一只读事务提取受版本、隐藏、采纳/距离偏好和双缓存记录约束的策展投影。随后以 dirty token 比对短事务提交关联、别名引用、计数及队列确认；读取后发生变化的 asset 不发布旧投影，下轮重读。无需第二次识别或全量源扫描。

初建或模型/地理偏好/本地词表变化时构建新 generation，构建完成才原子切换。旧代在此期间可查询，同时返回 building/stale/pending；未完成的词库不能解释为全库没有该词。工作进度跨进程保留；保留上一代，其他旧代及废弃构建按1000行小批回收。普通照片改动只更新相关 asset。显式“重建词库”仅递增本地词库 epoch，不入媒体队列。

## 策展工具和页面

新增 `lookup_keywords(query, domains, context, limit, cursor)`，返回标准 ID、显示名、匹配别名、模型/媒体版本、父区域、近似精度、上下文照片数及消歧标记。默认20条、最多60条，稳定游标绑定查询条件及发布代/修订；词库变化后提示重查。SQL使用参数绑定，LIKE中的通配符按字面转义。Settings 查询是发布索引计数；agent 的 context 计数按本轮当前策展快照重算，排除当前筛选范围外的照片。

`search_photos.filters.keyword_ids` 使用返回 ID；同域多个值 OR、不同域 AND，仍与年份、器材等原条件 AND。不得把别名再次塞入 query 叠加过滤。保留原 `list_facets` 及字符串筛选，兼容已有流程。overview只提供词库状态/规模，不向 provider 注入完整旅行地点词库。最终准备展览继续复验源 revision、隐藏、分析版本和实际双缓存文件。

Settings新增四个分类、词条检索/分页、别名/来源展开、照片数、歧义、待更新量和代际状态。使用共享导航、读取/失败/空状态组件；整页不滚动，侧栏及内容内部滚动。快速切词/卸载取消旧请求，首次读取、后台更新、空结果及错误分别展示；不显示异常堆栈或私密路径。策展过程使用现有穿插事件流显示“查询词库”。

受馆主鉴权的接口：

- `GET /api/lexicon?domain=subject&query=sport%20car&limit=20`，以及 city/topic/style。
- `GET /api/lexicon/status`。
- `POST /api/lexicon/rebuild`，沿用同源写保护。

## 验证边界

后端专项覆盖中英/全角别名、重复标签去重、同名城市、上下文数量、同域OR/跨域AND、无结果不扩展、隐藏/恢复、标签替换、缓存撤出、事务回滚、worker重建恢复/原子切换、并发 token/配置变化、旧代回收、过期模型、未采纳推断、分页更新与鉴权。模拟agent验证“查词→ID搜索→草案→准备”并在准备前隐藏照片，确认最终剔除。源GET计数保持不变。

浏览器使用84张生成照片和本地模拟流式 provider；检查中文词条/英文别名、来源去重、城市精度、空结果、过期请求取消、分页、显式重建、工具过程与Show照片墙。视口包括1500×940、1280×640、390×720、320×640和844×390。公开截图只使用合成库。

真实库验收只在本机读索引，使用存量元数据建立词库；未把私密图库发给真实provider。精确别名集合一致性不等于图像识别准确率或自然语言意图成功率。尚未加入上位概念自动扩展、行政区边界补全、模糊语义或向量检索；“惠州”缺分类值时仍不能凭拼音、活动标题或全省替代。

实际测试数量、构建资源和正式服务快照见[本轮汇总证据](keyword-lexicon-implementation-evidence.json)。复验操作见[项目skill](../../.agents/skills/photo-museum-media-validation/references/lexicon.md)。

## 本轮实测结果

156项全量后端测试全部通过，其中12项为词库专项；26项策展/词库补充回归、6项迁移/无变化写入回归通过。浏览器11项词库检查、8项导航回归和4项状态单元测试通过。构建通过，未增加运行依赖。

正式库首次构建11.46秒，索引18,246张可展照片，127,656条照片关联；主体997（991个标准类别及6个未消歧词条）、摄影主题19、风格14、城市271。4,918个规范化别名字串，28个域内歧义别名字串。含所有表和自动索引占121,794,560字节，约116.2MiB；与照片缓存分开，重建保留上一代时需额外同量空间。未打开图片、无网络尝试、未加载torch。SQLite quick_check为ok。

真实禁网审计的20个刻意选择的旧精确筛选缺失英文别名，全部返回同一标准类别的正确照片集合；索引计数与当前策展投影逐词完全一致。完整照片投影约6.88秒；复用该快照后的lookup工具查询平均约93.5ms、最大115.9ms，包含上下文计数及状态/别名/出处读取，不能与旧原型单条SQL微秒计时混比，也不是端到端LLM耗时。样本不是随机用户意图，不能据此宣称识别或自然语言成功率100%。

发布前完成schema9在线备份；升级先到10建立词库，真实进程检查发现既有媒体队列的相同stale写入会重复入队，因此schema11补充值变化guard。修正后连续78秒观察修订号及更新时间不变、pending=0、worker心跳持续。既有metadata、analysis、curation、media_info、people、faces内容摘要与备份完全一致，媒体队列状态、缓存账本数量与暂停偏好也保留；原有5个媒体兼容异常没有被本次重试。服务维持API＋5个worker，正式Settings页面已核对显示已同步。
