# 时空隧道返回动画修复

2026-10-26。

## 原因与修复

照片墙返回隧道走共享 `photo-close` 过渡。旧实现把所有非 Cover Flow 的目标元素当普通磁贴，直接用动画 `transform` 覆盖其布局变换。隧道画板自己的中心偏移、透视旋转和纵深缩放因此暂时消失，取消动画后突然恢复，产生错位和瞬移。

隧道目标现在只动画独立的 `translate`、`scale` 和透明度，不接管布局 `transform`。保留原有渐进入场节奏，动画完成与取消均回到同一布局。其他展厅和 Cover Flow 的入场分支保持原样。

另外，隧道重新挂载改为在 layout effect 中同步测量真实容器，确保动画测量前已完成布局，而不是先使用1200×700默认尺寸。打开活动时保存实际浏览位移；恢复时只采用与目标活动一致的位置，避免历史目标被旧位置覆盖。

## 复验

隔离P5合成图库，端口8798；构建与证据位于被忽略的 `data/spacetime-return/`。执行 `node web/tests/spacetime-return.mjs`。

修复前专项明确失败于“return must preserve perspective transform”；修复后检查桌面1600×900、手机390×844、矮屏844×390的页面返回及浏览器Back：动画不覆盖透视、入场前尺寸准确、原活动和位置恢复、动画尾帧无突跳。另检查中途Back/Forward的动画/克隆清理、Cover Flow返回回归及减少动态效果。没有使用真实照片或修改NAS。

正式静态发布先复制带hash资源，再原子替换HTML，不重启API和刮削worker。真实会话只验证进入活动和返回；私密截图保存在data，不提交Git。
