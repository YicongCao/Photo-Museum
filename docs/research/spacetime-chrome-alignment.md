# 时空隧道对齐 Cover Flow 界面

2026-10-26。以当前已认可的 Cover Flow 为参照，不新增概念方向。

- 标题复用同一套居中、日期/标题字体、颜色、字号、字距和响应式规则；删除旧的左对齐覆盖与42px装饰横条。
- Timeline直接使用同一个TimelineDrawer及玻璃CSS，年/月/活动无底色块，手机也使用纵向抽屉。保留Dock、评分预览、面板矩形自动展开、菜单防误触、Esc、键盘入口与减少动态效果。
- 桌面纵深终点向右延展，让远端照片能够经过玻璃面板下方；主封面起点不变，活动顺序、数量与精选算法不变。
- 位置条保留序号、拖动与键盘定位，使用共享细线轨道/滑块，去掉黑底，放在居中展签下方。隔离位置条pointerdown，避免同时触发场景拖拽；层级高于倒影、低于timeline。手机和矮屏分别避让标题。
- 时空隧道继续黑底；Cover Flow白天模式的范围不扩展。

验证：独立P5合成图库（8798），`node web/tests/spacetime-alignment.mjs`通过5组检查，覆盖1600×900、390×844、844×390的标题计算样式一致、无横条、滑块命中/键盘操作、无页面溢出、玻璃抽屉、导航/菜单防误触及减少动态效果。`gallery-chrome.mjs`的11组既有回归通过；无原图请求、无浏览器脚本异常。Vite构建成功。

截图和证据位于data/spacetime-alignment。正式8790只更新静态资源（先带hash资源，后原子替换HTML），没有重启API或worker。已用现有登录会话查看真实时空隧道并保留页面，私密截图production.png不提交Git。
