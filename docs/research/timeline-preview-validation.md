# Timeline 照片气泡与字号验收

2026-10-25。Gallery时间线活动项停留110ms后弹出照片预览；切换活动时旧气泡150ms收起，新气泡160ms后进入，220ms缓动展开。鼠标离开后70ms开始收起，滚动、Esc、点击选择活动及窗口缩放关闭预览。

## 选片与展示

- 复用`/api/gallery`已有严格评分Top10：只取有效评分的成片，降序排列后从前3、4、5张中选择平均裁切损失较低的拼贴。不会为了拼贴跳过高分照片。仅1–2张时展示真实数量，未评分显示状态，不补造照片。
- 三图是左大右双图，四图为2×2，五图为左主图＋右四图。桌面气泡统一336×236px，照片区318×180px。黑色毛玻璃、黄褐细边、右侧尖角与Cover Flow一致；保留主题和年月标签，移除重复的浏览器原生title提示。
- 通过Portal挂到body，避免timeline滚动裁切；始终对齐稳定按钮命中区，而非Dock放大后的文字。上下边缘自动避让，窄屏空间不足时改在时间线上方，宽度最多视口减24px。
- 只加载本地640px缩略图，不取4K或NAS原图；仅气泡出现后发请求。切换/关闭取消未完成请求、撤销Blob URL。失败项显示简短状态，不影响时间线选活动。
- 键盘focus与鼠标hover均可预览，Esc收起；减少动态效果时关闭弹出/收起动画。触摸点击保留直接选择活动。气泡不接管鼠标点击，点击活动的既有行为继续可用。
