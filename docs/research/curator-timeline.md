# 策展助理：按发生顺序的运行记录

2026-10-26。运行面板改为单条时间线：轮次 → 模型思考/文本 → 工具 → 下一轮思考。沿用黑底黄褐、细线图标和统一导航；左侧保留要求、最终结果、缓存准备与Show。

## 行为

- 以服务端持久化事件ID排序并去重，只合并相邻同类文本。思考和正文不再各自跨轮拼接；工具卡留在调用开始的位置，收到结果后原位补充耗时/错误和可展开的参数、结果。
- 相同工具call ID在不同轮复用也保留为不同调用；未收到开始事件的工具错误仍可展示。未结束的调用在取消/中断后不再声称执行中。模型内容仅展示provider实际返回部分，未返回时不补写思考。
- 每段显示实际事件时间与轮次。阅读旧内容时保留原有自动跟随边界；思考段不再拥有另一个独立滚动框，只在运行面板内滚动，段落仍可折叠。
- 固定面板标题旁新增细线环绕动画，区分等待响应、思考、文本输出、具体工具和展厅准备。显示距最近服务器记录更新的时间；断线明确显示重连且停转，结束/失败/取消后停止，减少动态效果时保持静态。动画表示已连接的活动任务，不把它当作远端输出进度或假百分比。
- 计时器仅在活动任务内运行，终止和卸载时清理；SSE仍使用原来的持久事件回放，不新增轮询、外部请求或付费请求。切换/提交新任务清除旧结果并拒绝迟到的旧任务事件与展览详情，防止新旧时间线混杂；回放历史阶段不能把已完成任务改回运行中。
- 不再截掉超过4000条事件之前的内容；单次任务仍受服务端轮次/输出长度限制，离开任务释放该页面持有的记录。

## 验证

前端隔离构建至`data/curator-timeline/web-dist`。以该目录启动P5 fixture，设置`MUSEUM_VALIDATION_CURATOR=1 MUSEUM_FIXTURE_PORT=8796 MUSEUM_WEB_DIST="$PWD/data/curator-timeline/web-dist" PYTHONPATH=.`，运行`uv run --all-extras python tools/p5_validation_server.py`。只使用84张合成图和本地fake provider，不读真实凭据、不调用真实模型。

- `node --test web/tests/curator-timeline.test.mjs`：4项通过，覆盖跨工具/轮次顺序、重复/乱序回放、复用call ID、无开始/未结束工具、真实阶段与终止状态。
- `node web/tests/curator-timeline.mjs`：6组通过。实际本地SSE形成5段思考和4个穿插工具，刷新顺序不变且无新模型请求；补充受控事件覆盖正文穿插、安静等待、重连、动画帧变化、减少动态效果、准备计数、取消/卸载计时器及连接释放。桌面、矮屏、320/390手机与390×540均无整页滚动。见[记录](curator-timeline-evidence.json)。
- `MUSEUM_TEST_URL=http://localhost:8796 node web/tests/p6.mjs`：11组通过，复验配置保密、思考/工具/准备、刷新、延迟4K与Show、六种集合展厅、手机、取消和空结果；本轮输出写在忽略的`data/curator-timeline/`，不覆盖历史验收图片。

回归中修复Show照片墙的已有时序竞争：展览详情返回前历史钩子已写入本次默认Cover Flow快照，不能据此误认为用户正在恢复旧记录。现在只检查挂载时已有的历史项，保留真正的Back/刷新恢复；延迟预热回归通过。
