## 实现

- FastAPI API、独立 Python worker、React 馆务室；本机启动器同时管理两个进程，退出不删除任务。
- SQLite WAL + 两个顺序迁移，迁移进程锁；目录领取采用 30 秒租约、5 秒心跳和提交令牌。进程死亡后可以重领，旧结果不能越过新租约提交。
- WebDAV 只使用 `PROPFIND` 与 `GET`，中文路径按段编码、不跟随重定向。Depth:1 一次取得目录子项属性，避免每个文件一次 HEAD。完整目录才提交；原片目录、RAW 和系统目录不纳入。
- 活动年份、可选月份、主题，以及物理文件路径、格式候选类别、大小、mtime、ETag、源版本入库。增量再次枚举所选范围，稳定路径保留资产 ID；原图内容不在目录扫描时下载。
- 暂停/恢复/取消、网络退避、认证或权限阻断、凭据更新、浏览器刷新后状态恢复。当前目录未完成时不提交半份结果。
- 单馆主密码 Argon2id；随机会话只存哈希，12 小时过期、HttpOnly、SameSite Strict、注销撤销。Host 和 Origin 校验，登录失败限速；验证错误不回显密码。NAS 凭据本地加密与文件权限限制。
- 资产 ID + revision 的鉴权 manifest 与原文件代理，支持单段 Range，有界流式读取；没有任意路径代理。尚无瓦片端点，不能绕过登录读原文件。
- 独立有界下载组件：强 ETag 下 Range/If-Range 接续，200 重下、416 重下、弱/缺 ETag 禁止拼接。完成文件原子替换，保存 SHA-256。
- 原始/推断/人工三层事实和按需 effective，提取状态、历史、精度/不确定范围、供体原始记录 ID 与版本。人工清空保持未知；待确认推断不进入 effective；来源或供体变化使相关结果陈旧。派生记录预留但尚不执行转码。

## 边界和后续

P1 是**文件级刮削底座**，未提取全库 EXIF，未运行 GPS/近邻推断、Live Photo 配对或 AI；未生成缩略图/4K/瓦片、未接正式 WebGL 场景。manifest 明确返回派生资源尚未生成。完整兼容派生任务执行器、effective 检索列和照片逻辑分组在 P2 完成。

暂不支持定时自动扫描；用户重新发起所选范围的扫描即可做增量发现。按源串行任务；暂停会等待当前有界读取结束，恢复后重读未提交目录。大目录上限、单次原文件 256 MiB/120 秒、spool 512 MiB 见运行说明，超限会明确拒绝，不宣称已经支持长视频完整读取。

缺少强 ETag 时，大小与 mtime 同时不变的内容替换不能可靠识别。当前已有强 ETag 的 NAS 小样证明续传能力，不证明 NAS 所有文件/服务版本都具备相同能力。HTTP 凭据链路只用于本次明确授权的内网验证；HTTPS 部署仍待证书修复及 P3 实测。

桌面 Chrome 手机视口模拟不等于真实手机或 Safari 验收。原文件下载成功不代表 HEIC 解码、显示色彩或 HDR 正确。未测试 Linux、Docker、反向代理或自动备份恢复。
