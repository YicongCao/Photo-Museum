## 搜索语义

- Gallery 右上角放大镜 → 检索。文字按空格分词 AND；不假装理解自然语言。国家、省份、相机、姓名、日期、已标记及推断开关，可组合关键词 ID。
- 主体、摄影主题、摄影风格、城市仍是不同域；同域 OR、跨域 AND。中英文通过真实词库选择标准 ID，不猜城市或扩展上位概念。
- 普通入口默认主体“首选候选”：只取模型第 1 位或人工确认；“全部候选”需用户明确切换；“仅人工确认主体”不等于所有照片必须有人物确认。模型顺位与 softmax 分数不是正确率。
- 兼容既有 agent 查询的默认 all；schema 提示主体明确的请求优先 primary，没结果不自动扩大范围。所有模式都尊重人工排除。
- 地点仍为 GeoNames 最近城市，并非行政区边界判定。无有效地址不由活动名或附近镇名补造城市。
- 点击标签旁 ✓ 确认、× 排除；最近修订可撤销。恢复记录使用 token，过期撤销不能覆盖后续操作；更改已有标记须先撤销。确认绑定照片 revision，模型更新不丢人工确认，文件 revision 改变后旧确认不再作为命中依据。
- 显示每个标签顺位/人工确认、近似城市、活动与日期。直接点图复用单图；展开照片流复用全量布局、原图按需加载与 History 返回。
- 搜索定义仅在服务器保存筛选条件，30 天清理；分页/展开时按当前隐藏、revision、模型有效性重新核对。浏览器不持久保存结果照片清单；切换展厅内存保留，重载保留筛选草稿、需重新检索。

## 代表性策略

- Settings → 照片显示 → 封面选片，默认 top10，可选择代表性精选并保存。两排缩略图对比不写设置、不取原图。
- 候选先应用现有隐藏/占位/有效评分规则。美学全部补齐后统一使用美学，否则统一回退技术分，绝不混排尺度。头图始终为最高分照片。
- 贪心选至最多 10 张：相对质量 0.55（归一化分母至少美学 2 分/技术 20 分，避免很小分差被放大）、拍摄时间覆盖 0.25、已有 dHash 差异 0.15、首位主体候选差异 0.05；dHash 相似度 ≥0.92 扣 0.7，降低连拍重复。按原评分/路径/ID 稳定打破并列。
- 缺拍摄时间、signature 或主体不获得对应多样性奖励；过期 visual 不参与 signature/主体比较。没有强行用低分或隐藏照片补足十张。
- 这是一种可解释启发式，不声称懂活动叙事。dHash 不是可靠的同场景/同机位识别；设置中可直观看差异，再由馆主决定是否采用。
- 此轮不加入手工封面编排、人物权重、个人审美训练；保留单张标记含义，不用星标暗中覆盖排名。策展限定集合的既有展示选择保持其原规则。

## 验证与准确率边界

- 合成检查可证明模式、域组合、版本隔离、人工纠正/撤销、权限、零 NAS 请求与稳定排序；不能证明真实分类准确率提高多少。
- 需要馆主在真实查询中积累确认/排除，才能计算 precision@k。此轮不替馆主判定真实人物或喜欢哪张照片，不凭候选数量下降宣称准确率提升。
- 回归发现旧 schema 模拟 helper 未移除 runtime/search 后增对象，导致迁移重放冲突；修正测试夹具后重测。未改历史迁移来迁就不真实的旧 schema。

## 验收入口

1. Gallery 右上放大镜 → 选地点、时间、相机或词库词条 → 检索。首选候选没有结果时，可由用户明确切换全部候选。
2. 在照片标签旁确认/排除误判；最近修订可以撤销。模型候选顺位不是准确率。
3. Settings → 照片显示 → 选片对比，选一个活动比较两排照片；决定采用后选“活动代表性精选”并保存。
4. 本轮普通搜索只检索具备可展示缓存的照片，未加入独立视频全文检索、语义向量召回或行政区边界反查；这些不能从本轮交付推断为已完成。
