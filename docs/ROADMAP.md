# 推进路线与验收门槛

2026-10-24修订：依照 [ADR 0002](decisions/0002-immersive-viewer-and-inference.md)，先验证全画布观展，再实现正式UI。每阶段更新`STATUS.md`与`docs/logs/`，只将实际跑通的步骤沉淀为项目skill。

## P0 — 实测与方案（已完成；方案已修订）

已有只读盘点、媒体小样本、索引/provider研究、缓存估算。原HTML概念现在仅作历史色彩/气质参考，不作为全屏WebGL交互验收成果。无需重跑全库来修改产品计划。

## P0.5 — 全画布与渐进原图风险原型（下一步，未开始）

用少量可控的合成资源和真实格式样本建立一个Three.js/WebGL持久canvas。先验证B主题布局＋单幅细看，再用简化F照片墙证明场景能复用同一运行时。此阶段不建设完整A–F，也不下载全库原图。

退出条件：

- 缩略图→优先4K→后台原图/兼容高分辨率图的状态真实；解码及纹理/瓦片就绪才显影。原图快于4K时不降级，已缓存时不故意等动画，失败不黑屏。
- 快速切图、关图、源版本变化及请求取消不会让迟到结果覆盖当前图；释放不再使用的纹理、ImageBitmap/视频解码资源和临时引用。
- 原图尺寸超过设备最大纹理时采用分块/LOD，缩放看细节保持清晰；不把缩小纹理叫全分辨率原图。照片不受3D场景灯光意外染色或重复tone mapping。
- 1440桌面、390手机和高DPR下测帧时间、CPU/GPU资源估计和解码峰值，建立分档预算；实际设备结果决定阈值，不先承诺所有设备60fps。WebGL上下文丢失/恢复与不支持时有明确路径。
- 全屏需用户手势的行为、Esc退出、触摸缩放/拖动、键盘/读屏语义及减少动态效果均通过。
- 提前验证浏览器原生解码/HDR与WebGL纹理的能力边界；原生HDR正式实现仍在P3。不能因为img/video可显示HDR就宣称canvas支持。

## P1 — 稳定数据、推断与媒体接口底座

交付：Python API＋独立worker、只读WebDAV适配器、本地SQLite migrations、任务租约/退避/暂停恢复、密码鉴权与源配置。同步建立：原始/推断/人工/effective字段、供体依赖及版本；媒体manifest、源版本、鉴权原图代理、可取消/有界的读取与兼容派生任务。

验收：受控WebDAV fixture与单个真实活动。覆盖断网、worker中断、权限/认证失败、弱/缺ETag、中文路径、目录内新增、旧文件变更；只有完整成功枚举才能判断缺失。原路径由内部asset映射，无任意路径代理，原图/瓦片/Range接口全部鉴权。

Range＋If-Range/强校验可用才续传；源变更/不支持时安全重下临时文件。下载恢复与任务恢复分开呈现。人手修订、真实EXIF及推断不互相覆盖；供体变更能定位需要重算的字段/地址。

## P2 — 可浏览首版：主题场景与暗房细看

交付：EXIF、可靠SDR双缓存、同目录文件名近邻补全、统一canvas的B主题浏览、4K→原图显影、按需高分辨率兼容图/瓦片、缓存预算与LRU、基础十图策展、Live Photo/视频中点封面与播放、React刮削管理。

验收：多时期JPEG、HEIF/HIF、手机HEIC、竖图、RAW混排、年度活动、配对与独立视频。观展无传统页面滚动相册，DOM仅用于必要语义/输入辅助，视频通过解码资源接入同一画布。每张照片的GPS/时间是原生还是推断可查；设备混序、编号回绕、异地供体、缺EXIF及真实EXIF补回的正反例通过。

满缓存时原图/瓦片/临时文件均受总额度限制，已有4K持续可用；重启恢复；缓存不删除NAS原图或人工数据。未登录不能读任何照片、元数据、任务。浏览器实际验证色彩、方向、缩放、显影、输入和错误状态，不以合成图演示代替真实媒体验收。

## P3 — 原生媒体与可移植部署

交付：经验证的HDR/广色域显示、Mac/Linux/Docker构建与codec能力说明、可信TLS、备份恢复。沿用单canvas要求，先测原生文件→纹理→输出是否保留预期色彩/HDR；不能未经用户决定改用覆盖在画布上的DOM原图来绕过架构。

验收：Safari/Chromium、SDR/HDR屏幕、PQ/HLG/gain map、视频seek等分列。暂不能在目标画布路径正确显示的HDR明确使用准确SDR回退；如必须采用额外原生媒体显示模式，应单列关键取舍再征求用户意见。Docker初始化、迁移、备份恢复实跑；未测平台不标通过。

## P4 — 本地智能策展

交付：本地人脸聚类/人工标签、语义与美学特征、十图多样性选择、可替换provider及模型版本；可选地址解析。基础文件名推断已经在P2，不能等到本阶段才补。

验收：不覆盖用户固定精选/人物/地点；模型升级只失效相关阶段；本地识别离线可用。精确GPS/推断地点的精度能贯穿逆解析和地图，城市级推断不制造街道级事实。选片以用户认可、覆盖与冗余程度验收。

## P5 — A/C/D/E/F展厅扩展

在已验证的运行时上补齐F照片墙/放映 → C日历 → D地图 → E器材馆 → A时空隧道。B随P2完成。各场景共享选中项、日期锚点、媒体优先级、纹理池、输入与状态恢复，切换不新建canvas。

地图使用可替换数据/瓦片provider，由同canvas绘制，保留版权署名与坐标系转换；不是嵌入另一块地图canvas。全屏墙以UV裁切近方格满铺，单幅细看恢复全幅。每场景分别验证可见对象裁剪、文本清晰、点选命中、手机操作、低动态效果与显存回收。

## P6 — 可选策展助理

确需多轮自然语言策展时接OpenAI受限工具，输出可审阅展览草案。刮削、邻图推断、媒体加载、显影动画与基本搜索不依赖agent；识别仍本地。禁止任意shell/NAS写入，远程数据字段按具体功能限定。
