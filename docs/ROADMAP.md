# 推进路线与验收门槛

每阶段完成后更新 `STATUS.md` 与 `docs/logs/`，记录已验证、未验证、证据与下一步；跑通流程沉淀为项目 skill。不同阶段可以有小范围验证并行，正式功能按依赖推进。

## P0 — 实测与方案（当前）

交付：只读库盘点、媒体小样本、索引/识别/provider 调研、缓存预算、视觉概念、决策记录。盘点须列出完成范围、排除规则和错误；小样本须区分 SDR 成功与 HDR 未验证。

退出条件：明确成片候选规模、格式/配对风险、基本缓存空间；用户选定首版目标和视觉主方向。不能把 P0 工具当成生产 scraper。

## P1 — 稳定数据底座

交付：Python API 与独立 worker；WebDAV 只读适配器；SQLite migrations；任务租约/心跳、失败退避、暂停恢复；密码认证和日志脱敏；源连接配置。

验收：用受控 WebDAV fixture 与真实 NAS 单个活动完成扫描；对 worker 中断、网络中断、认证过期、ETag 变化、无 ETag、目录新增文件、Unicode/URL 路径、同名/重复、分页和权限错误做行为测试。只有列举完整且成功才能确认缺失项；扫描期间消失文件不导致全局删除。

下载恢复：Range + If-Range/强校验可用才续传；不支持、弱 ETag、内容变更或校验失败就安全重下临时文件。恢复状态指的是任务和可验证字节，两者分开展示。

## P2 — 可浏览的首版（P1 基础上）

交付：EXIF 元数据、可靠 SDR 衍生图、缓存预算/LRU、活动索引和暗色灯箱、时间覆盖与去近重复精选基线、Live Photo 与视频中点封面；扫描管理页。

验收：至少挑选旧 JPEG、相机 HEIF/HIF、手机 HEIC、竖图、视频、Live Photo、原片混排、年度主题各类真实活动。浏览器按需加载、不会一次下载全库；筛选分页稳定；未登录的 API/缩略图/原图均不能访问；缓存达到上限时总预算包含临时文件；服务重启恢复。桌面/手机手工验收照片方向、色彩、裁切、键盘操作、登录退出。

## P3 — 原生媒体与可移植部署

交付：HDR/广色域输出能力协商；可信证书连接；Docker Compose、卷备份恢复；Mac、Linux CPU 和 Linux/ARM 解码能力说明。

验收：Safari 与 Chromium 实机、SDR 与 HDR 屏幕、原生兼容与服务端回退都要单独记录。HDR测试集包含PQ/HLG、gain map与SDR。Docker全新启动、密码设置、数据库迁移、重建缓存、备份恢复都必须实跑；未跑到的硬件列未验证。

## P4 — 本地智能策展

交付：本地人物聚类及人工标签、语义向量、审美/技术评分、主题十张多样性选片；配置可替换provider、下载模型和校验版本；可选逆地理编码。

验收：选片不能十张几乎一样，不自动覆盖人工锁定；人物错误合并可撤销；模型版本改变只重跑受影响阶段；GPS结果可空且可修订；断开外网时本地识别正常。用用户认可/替换比例衡量“选得好”，不以模型分数自行验收。

## P5 — 创意展厅

顺序建议：主题长卷 → 满屏墙与屏保 → 年/月/周日历 → 地图 → 器材馆 → 时空隧道与更多回忆方式。每种模式先验证一段真实展览，再扩展整库。避免全库 DOM、3D 层和纹理同时驻留。

## P6 — 可选策展助理

仅在确有不可由确定性筛选替代的需求时接入 OpenAI。例如用户用自然语言提出“把过去十年的海边旅行组织成展览”，agent 查询本地元数据与用户标签，给出可预览、可撤回的展览草稿。基础导入、缩略图、选片与搜索不依赖它；人脸/主体识别仍本地。

工具只提供有界查询与草稿操作，禁止任意 shell 和 NAS 写入。远程发送的字段/图片边界需按具体功能明确，不能因已配置 key 自动上传整库。
