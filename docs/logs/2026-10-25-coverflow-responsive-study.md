# Cover Flow 排版研究

用户请求思考多屏宽布局，本轮仅制作独立设计草案，未修改/部署正式应用。检查了当前阶段、依赖与源计算；发现700/701px封面骤降420→120px及非对称右侧裁切。方案分离主图尺寸、两翼清晰层数与5–20驻留预算，保持屏幕中轴，按高度限制主封面，超宽约900px封顶；小屏时间线折叠仍待用户取舍。

成果为docs/design/coverflow-responsive中的独立HTML/JS，公开SVG合成画面；10种尺寸、逐像素宽度连续性、明暗/方案切换和390px报告控件经Chrome检查。模型不等同生产实现，三级导航展开与真实手势尚未制作。正式8790与后台刮削保持运行。
