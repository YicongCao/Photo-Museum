# Gallery 概念图与新增展厅构思

使用内置image_gen生成10张最终PNG：已有6种形式（Cover Flow、活动墙、日历、地图、器材、隧道），新增4种构思（人生年轮、记忆星图、记忆长卷、故地重游）。首张Cover Flow竖幅初稿已单独修成横向3:2；参考仅为同轮AI图，没有读取或上传NAS照片、EXIF、脸特征、精确GPS或凭据。

最终图均复制至docs/design/gallery-concepts-2026-10-25，10图约18.7MiB，PIL解码/尺寸与SHA-256清单齐全；完整提示词保存在manifest。新增展厅的用途、交互、现有数据复用与缺口、近似地点/候选标签边界均在design-notes中说明。优先建议故地重游与记忆长卷，不自动改为新的实施计划。

独立对照页支持6/4分类、大图、箭头翻页、Esc及焦点恢复；6项浏览器检查通过，包含10图解码、390px与离线file打开。初轮直接decode惰性图片过早触发EncodingError，复核HTTP与PNG均正常，等待图片实际载入后完成全量验证；未为测试修改图像。机器证据见docs/research/gallery-concepts-browser-evidence.json。

对照页已在内置浏览器打开并标记保留，复用只服务公开docs的8799预览服务。正式Gallery、8790服务、刮削与配置均未修改。图像是视觉提案，不冒充真实UI或未开发的新展厅；生成地图、器材线稿、日期/数量均不作事实依据。
